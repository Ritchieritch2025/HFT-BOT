# 阶段 2 · 裁决(**全部离线,不碰实盘**)

## T2.1 · 预测包容检验(kill-test,放最前)【S】⭐

**依赖**:已封存结算数据
**产出物**:`estimation/encompassing.py`,输出 `settle ~ a·logit(fair) + b·logit(mid)` 的 a、b 及按市场聚类的 CI;分 tte 层。
**验证命令**:`python -m estimation.encompassing --oos-only`
**事先写死的读法**:

| 结果 | 结论 | 后续 |
|---|---|---|
| **a 显著 > 0** | fair 含中价没有的信息 | 定价核值得继续投入 |
| **a 不显著** | **模型 edge = 0,fair 只是中价的噪声版本** | **停止定价核精雕,资源转执行链;阶段 3 的 `as_estimate` 仍做(它测的是流,不是价)** |
| a 显著 < 0 | fair 系统性差于中价 | **定价核有 bug,回阶段 1 查** |

**通过线**:无"通过/失败",这是**分叉门**。但必须满足:有效 cluster 数 ≥ 100,否则标 `NOT_ESTIMABLE` 并等数据。

## T2.2 · 条件鞅检验 【M】

**依赖**:T1.3
**产出物**:按 (moneyness × tte) 分格的 `E[Δfair|格]` 与 CI;**按 |vega| 加权排序输出"定价 bug 清单"**(vega 在两翼最大,不在 50¢)。
**验证命令**:`python -m estimation.martingale --conditional`
**通过线**:
- **无条件版 |E[Δfair]| 的 CI 必须含 0**(不含 0 = 定价核有系统性 bug,**先修再往下走**);
- 条件版输出清单即可,不设阈值。

**失败处置**:无条件版不过 → **阶段 2 其余任务全部暂停**,因为 AS 的定义依赖鞅性。

## T2.3 · 对照组回归 【L】

**依赖**:T1.1、T1.4
**产出物**:`Δfair = α + β·1{成交} + γ·状态 + δ·(成交×状态)`,跑在**所有报价时刻**上;市场窗聚类 bootstrap。
**验证命令**:`python -m estimation.control_regression --cluster market_window`
**通过线**(三条健全性,全过才可用):
- **α 的 CI 含 0**(内嵌鞅检验/安慰剂);
- 未成交样本数 ≥ 成交样本数 × 20(否则对照组太薄,标 `WEAK`);
- YES/NO 两侧 β 符号一致、幅度可比。

**失败处置**:α 显著非零 → 回 T2.2,**别继续拟合 δ。**

## T2.4 · EB 收缩 + 首版 Params artifact 【M】

**依赖**:T2.3
**产出物**:`w = n/(n + σ²/τ²)` 逐格自适应;产出带 `sha256` 的 `Params`;**大盘先验只进符号/排序,幅度由自家样本定。**
**验证命令**:`pytest tests/test_shrinkage.py -v && python -m params.verify artifact.json`
**通过线**:
- 人造 n=3 的薄格,`Est.sd` 显著大于 n=1000 的厚格;
- artifact 含 `train_window`、`fitted_at`、`sha256`,校验通过;
- **全仓库模型参数类环境变量数 == 0**(`grep -c "MM_.*=" | 只剩运行配置`)。

**失败处置**:先验幅度泄漏进参数 = 违反 MATH_SPEC §6.7,**重做。**

## T2.5 · AS(h) 曲线含亚秒段 【M】

**依赖**:T1.3
**产出物**:`h ∈ {20ms,50ms,100ms,250ms,500ms,1s,2s,5s,30s,90s,结算}`;**h<1s 用币安隐含概率为参照,h≥1s 用 Kalshi 中价**;h\* = 实测撤单往返延迟。
**验证命令**:`python -m estimation.markout --with-subsecond`
**通过线**(健全性):
- 短尺度 MO(h) 随 h **单调非增**;
- **随机时刻假成交(安慰剂)的 MO 的 CI 含 0**;
- **R1 与 R2 在 h=1s、2s 读数一致**(差异 CI 含 0)。

**失败处置**:安慰剂不为零 → 我们量到的是漂移不是选择,**整套 AS 结论作废,查换算。**

# 计划失败的先行指标(每周看,别等终验)

| 症状 | 说明 |
|---|---|
| 阶段 1 的任务改变了行为 | "只照明"纪律破了,后面所有对比失去基线 |
| 出现第二个回答"这笔危不危险"的地方 | 单一真理源被绕过,回到今晚的四闸乱局 |
| 某条通过线被"临时放宽" | 事先写死的意义消失,记一次并复盘 |
| 收据里出现无 `params.sha256` 的结果 | 参数溯源断了 |
| 连续两周没有任何任务被判失败 | **通过线设得太松**,不是我们太强 |
