## 1 · 为什么(一段话)

Stage A 全红的死因是**退出规则主动横穿点差**(每 3 小时交一次 5–10¢ 过路费),不是市场看穿了我们。A2 已改为双腿被动,但它的报价规则仍是**手拍常数**(进场塞 d tick、出场挂 entry+e)。A-S 给出报价位置的**闭式解**:报价中心随库存偏移、点差宽度随波动/剩余时间/客流强度伸缩。本计划把 A2 的手拍规则升级为 A-S 参数化规则,**自由参数不增反减**(d,e 两个手拍数 → γ 一个风险参数网格,k/σ/A 从数据估)。

## 2 · 模型(Kalshi 记法)

工作空间:**log-odds**(y = ln(p/(1−p))),避免 0–100¢ 边界畸变;报价换回价格空间时按 tick 取整。

**保留价**(报价中心):
```
r_t = m_t − q_t · γ · σ² · (T − t)
```
m_t = 当前中价(log-odds);q_t = 净库存(张,买 YES 为正);σ² = 该市场层的 log-odds 中价方差(单位时间);T = **结算时刻**(Kalshi 天然终点;区别于原文的强平终点——见 §3.1);γ = 风险厌恶,唯一的自由参数。

**总点差**(围绕 r_t 对称摆放 bid/ask):
```
δ_total = γσ²(T−t) + (2/γ)·ln(1 + γ/k)
```
k 来自吃单到达强度模型 **λ(δ) = A·exp(−k·δ)**:挂单距中价 δ,被吃概率随 δ 指数衰减。A、k 逐层从 tape 估(§4)。

**行为直觉核对**(审计可拿这四条做冒烟):库存越多报价越往甩货方向压;σ 越大挂越宽;离结算越近挂越窄(风险项衰减);客流越密(k 大)挂越窄抢量。

## 3 · Kalshi 适配(机制可移植,假设逐条改)

**3.1 终点条件 = 结算,不是强平。** 原文 T 时刻必须清库存;我们 T 时刻库存按 0/100 真值兑付。实现:持有到结算为默认;(T−t) 风险项照用(它定价的是"结算前中价还会晃多少"),**但不加终点强平惩罚**。CARRY 持仓按可执行 bid 标记(禁 midpoint),沿用 A2 口径。

**3.2 知情流显式除外。** A-S 假设吃单是无脑泊松流,不建模逆向选择。本计划**不试图**在报价公式里塞毒性项;防知情流 = VPIN/撤退层的职责(另一条线,EXPLORATORY 中)。审计应确认:本计划任何地方**没有**偷偷用未来信息或毒性信号。

**3.3 稀疏书适配。** 政治盘成交稀疏,λ(δ) 拟合按**事件类别层**聚合(不逐市场),分层原则(2026-07-25)约束:参数不跨层移植。

**3.4 tick 与费用现实。** 报价按 1¢ tick 取整;费用 = maker 费按单向上取整(1-lot 进位罚 1–3¢,审计裁决在案)。回测按 Stage B 实际 CLIP 算费用;**若模拟 CLIP=1,报告里必须并列 25-lot 费用口径**,防止"1-lot 费用杀死真 edge"的误判(audit 钉子2)。

## 4 · 参数从哪来(全部 TRAIN 内,封印后不许动)

| 参数 | 来源 | 方法 |
|---|---|---|
| σ²(逐事件类别层) | TRAIN 窗口 L1 中价序列 | log-odds 中价的实现方差,按层聚合;禁用任何 VALIDATE 数据 |
| A, k(逐层) | TRAIN 成交 vs 挂距 | 对历史吃单流拟合 λ(δ)=A·e^(−kδ):按"成交价距成交前中价的距离"分桶数频率,指数回归。**这是力学模型线(S&C 方法)的第一个正式雇主;初版允许简单分桶拟合,不等 ML 版** |
| γ | 预设网格 {0.5, 1, 2} × 层基准 | **唯一自由参数**;网格在 prereg 里写死,TRAIN 上选,封印进 TRAIN_SEAL |
| T | 每市场结算时刻 | catalog_normal(带收据) |

## 5 · 实验设计(Stage A3)

**5.1 窗口纪律(继承 audit 触碰封顶裁决):** A2 是现 VALIDATE 窗口(07-17..22)的**第二次也是最后一次**触碰。因此:
- 若 A2 结果**尚未开封**:A3 可申请**替换** A2 的报价规则部分,合并为一次触碰(需 strategy+audit 会签,收据记明);
- 若 A2 已读:**A3 的 VALIDATE = 全新窗口**(07-23 起新封存日,攒 ≥5 个干净日再开考)。TRAIN 可沿用 07-10..16。
**默认走后者**,不抢时间。

**5.2 格子:** γ ∈ {0.5,1,2} × 侧 {YES,NO} = 6 格(与 A2 同规模,BH 分母=全部格数+A2 已用预算,预算表附收据)。

**5.3 对照(三条,缺一不合格):**
1. **A2 固定 d/e 规则**(同池同窗)——A-S 必须打赢手拍规则才配存在;
2. **消融:对称 A-S**(去掉库存偏斜项,只留点差公式)——证明偏斜项本身值钱,而不是"宽挂"值钱;
3. C1 时间打乱 + 随机选池(沿用 A2 口径)。

**5.4 成交与成本:** STRICT 最差排队(对面可执行价穿过挂价才成交)、1-tick 不利折价、费用按 §3.4、结算真值兑付、cluster bootstrap ×10,000、按事件类别分层报告。

**5.5 判决规则(预先写死):** 主格(γ=1)VALIDATE 净/张 ≤0 → 杀;赢不了对照1 → 杀;消融显示偏斜项无贡献 → 降级为"纯点差公式"再审。任何"调 γ 网格后再考同一窗口"= 禁止。

## 6 · 引擎 known-answer(实现完成、碰真数据之前全绿)

1. 合成扩散中价 + 泊松流上**复现 A-S 原文结论**:库存感知 vs 对称挂中价,均值相近、方差显著更小。复现不出 = 引擎实现错;
2. 单调性四连:q↑→报价下压;σ↑→变宽;t→T→变窄;k↑→变窄;
3. 边界:p→1¢/99¢ 时 log-odds 空间不产生越界报价;
4. 零库存时 bid/ask 关于 r 对称;
5. 费用进位:1-lot 费用 = 逐单进位,25-lot 摊薄,两口径并报。

## 9 · 给审计 agent 的攻击清单

1. **前视泄漏**:σ/A/k 估计是否只用 TRAIN?选池条件是否用了 VALIDATE 期信息?
2. **自由度审计**:名义上只有 γ,但 log-odds 变换、分桶宽度、层定义是否构成隐藏旋钮?数一遍全部可调项。
3. **触碰纪律**:§5.1 两分支是否严格执行?收据里是否可核?
4. **库存偏斜 = 变相方向赌?** 偏斜项会让库存亏损时"越亏越挪价"——验证它不会在趋势市里演化成追跌;要求报告按"趋势日 vs 震荡日"分层的库存轨迹。
5. **λ(δ) 拟合质量**:指数形式在稀疏政治盘是否成立?残差图必须附;拟合差的层是否诚实标 NOT_ESTIMABLE?
6. **费用口径**:两口径是否全程并列?有没有任何格子偷用 25-lot 费用配 1-lot 成交假设?
7. **known-answer 是否先红后绿**(修实现前应有失败记录)?
8. **与 A2 的可比性**:同池同窗同成交模型,对照才有效——逐项核。
