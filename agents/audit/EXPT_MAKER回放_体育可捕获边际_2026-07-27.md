# 实验设计:maker 视角回放——体育两端毛边际有多少能落到我们的挂单上

> 设计:Cowork Claude · 2026-07-27
> 依据:REPORT_FLB_分层测量结果_2026-07-27(sports_prop 95-99¢ YES 高估 +5.86pp [5.47,6.25] n=15,663,3.6× 成本;终局彩票税 +16pp 对称)
> 待裁决的 doctrine:「我们的 edge 只能来自流动性服务费与速度,不能来自捡错价」(FLB-01 封存时立)——本实验是它的第一次直接检验。
> **本实验只测量,不产生任何交易动作。** 代号:**MR-01**。

---

## 一、唯一的问题(可证伪)

**FLB-20260727 测到的对手盘超付(= 全体做市商毛利),按真实排队规则回放,有多少能落到我们体量的被动挂单上?扣除逆向选择(尤其跳空瞬间被扫)后净剩多少?尾部最坏账单是什么?**

三个必须分开的问题,本实验只回答 ③(FLB 报告回答了 ①,②的判据已收集):
①偏差存在 → ②错价 vs 风险溢价 → **③我们能不能收割**。

明确不回答:该不该上线(那是账单获批 + 操作员裁决的事)。

## 二、范围与预注册主格(防多重比较)

只跑体育两族。**主格(唯一有判定权的格,预先锁死):**

- **P1**:sports_prop · YES 95-99¢ · >60m(全表最大统计力,n=15,663)
- **P2**:sports_game · 终局 20-35¢ · <10m,双侧(彩票税最纯的格)

其余格(prop 1-5¢ NO 侧、90-95¢ 等)全部**探索性**,结果只进附录,不进结论。

**pre/in-game 拆分**:比赛开始时刻取 catalog 的 event 元数据(strike_date/预计开赛);取不到的市场从拆分中剔除并报告覆盖率——不许用成交密度代理硬凑。

## 三、回放口径(全部写死在代码里,悲观取向)

1. **虚拟挂单**:在格内每个市场、目标价位 p 挂 1 张(clip=1,与 A 档实值一致);到价即挂,排队从**队尾**起算(L1/全簿该价位当时全部显量都在我们前面);
2. **排队推进 = 只认成交**:我们前面的量只因成交打印减少;**撤单一律假设发生在我们身后**(无法区分撤的是谁 → 按对我们最不利处理,与"悲观成交"口径纪律一致);
3. **成交判定**:该价位累计成交量 > 挂单时点排队量 + 1 张,才算我们成交;
4. **无市场冲击假设**:clip=1 时成立;本口径**只对 ≤5 张有效**,容量外推禁止;
5. **持仓到结算**,maker 费 0,无平仓腿;
6. **跳空解剖(并入的 C)**:成交时刻落在跳空事件(FLB 口径:相邻成交 yes 价跳 ≥30¢)±60 秒内的,单独标记为 gap-adjacent,分开报;
7. **16 日切 11+5**:前 11 日设计段(可看可调),后 5 日确认段(**只跑一次**,跑前本文件 git 提交号即为封版凭证);
8. 样本单位 = 市场;cluster bootstrap ×1000;种子 20260728。

## 四、必须同时报告的六个数(每格)

1. **可捕获净边际** ¢/合约(成交加权,95%CI)——主数;
2. **捕获率** = 我们的净边际 / 该格 FLB 报告毛偏差;
3. **成交率**:每挂单小时成交张数(衡量周转,不是只看单位边际);
4. **gap-adjacent 成交占比** 及其单独净边际(逆向选择的显式定价);
5. **容量上限**:我们成交量占该价位总打印量比例(clip=1 与 clip=5 两档);
6. **四行最坏账单**(军规格式,精确数字,禁 σ/VaR):单笔最坏 = risk_px×clip;瞬时最坏 = 格内同秒最多同时在挂张数×最坏价;会话最坏 = 确认段单日最坏实测;线最坏 = 16 日累计最坏回撤。

## 五、预先声明的健全性检验(不过 = 口径或代码有问题)

1. **守恒**:任一价位任一时刻,我们的虚拟成交 ≤ 该价位实际打印量;
2. **无前视审计**:每个挂单/成交决策引用的数据时间戳必须早于决策时刻,自动断言;
3. **安慰剂格**:在已证明定价公平的格(crypto_15m 35-65¢,FLB-01 与本次报告双重确认)跑同一回放,净边际必须 ≈0(CI 含 0)。若安慰剂格也"赚钱",回放引擎在造钱,全部结果作废;
4. **悲观单调性**:乐观成交变体(撤单算在我们前面)的边际必须 ≥ 悲观变体,否则排队逻辑有 bug。

## 六、判定门槛(预先写死)

- **PASS**:P1 或 P2 在**确认段**净可捕获边际 >0 且 95%CI 不含 0,且 gap-adjacent 剔除后仍 >0 → doctrine 存活,凭四行账单走审批流程;
- **FAIL**:主格确认段 CI 含 0 或为负 → **「流动性服务费」这条路在体育两端也不成立**,与 07-23 两池两法全灭合并,主动对赌 + 被动收税两类打法全部出局,资源转 MR 以外方向(结构性 / MM-V2 速度线);
- 探索格无论多好看,不改变判定,只能生成下一个预注册。
