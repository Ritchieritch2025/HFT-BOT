## 2 · 分层架构(组件化原则的正确形式)

**不变式不是「无状态」,是「无隐藏输入」:所有状态必须能从记录的事件流完整重建。**

| 层 | 允许 | 要求 |
|---|---|---|
| **状态更新层** | 有状态(EWMA、锚缓存、订单簿镜像、持仓、deadman、事件时钟) | **给定同一事件流,状态演化确定** |
| **决策层 `core/`** | 纯函数,输入只有 `State` + `Params` | **零 I/O、零 `os.environ`(CI 强制);同输入同参数逐位确定** |
| **执行层 `runtime/`** | 真实世界的不确定反馈(下单、撤单、重试、对账) | 所有事件落盘,可重放 |

**EWMA、库存、订单队列全部合法**——它们住在状态更新层,其输出作为字段进入 `State`。
**决策层看到的是快照,不是世界。**

- **实盘凭据独占检查**:同 API key 已有行情连接 → **拒绝启动实盘**;
- **`BlockReason` 穷尽计数**:`Σ(各 reason) == 评估数 − 报价数`,误差必须为 0。

### 5.2 W1 · 照明(**不得改变任何决策行为**)

四段账 ledger + `staleness` 首次点亮 → 条件鞅检验 + 对照组回归 → 连打刹车 → **盾的 gamma 修正** + bump 自然尺度化。

**W1 出口检查**:同一段 tape 回放,W1 前后**决策序列逐条相同(diff 为空)**。
**不同 = "只照明"纪律被破坏 → 回滚重来。**

### 5.3 W2 · 裁决(全部离线,不碰实盘)

**A0 包容检验最前(kill-test)** → 六指标面板自动化 → lead-lag(两版) → EB 收缩接毒性表。

**lead-lag 必须跑两版:**
```
Δmid(t→t+h) = β·(fair − mid)(t)        # 我们的模型领不领先市场
Δmid(t→t+h) = β·(币安隐含 − mid)(t)     # 信息路径的领先存不存在(绕开自家模型)
```
**后者才是速度赛道是否开着的判据**——`fair` 建在 RTI 慢源上,用它测会问错问题。

### 5.4 W3 · 定价替代闸门

GLFT 接线(ΔL 价差替闸门,影子先行,实盘另批)→ 归因周报(A–D + 基准阶梯)→ 实验注册表与晋升/降级流水线常态化。

**迁移必须绞杀式四步**:新核只算不用 → 逐笔差异报告(**无法解释的差异数 == 0** 才可继续)→ 影子切换 → 实盘切换。**每步可回滚,旧代码保留一个回滚周期。**

### 5.5 押后不动

延迟反事实模拟、**闭式 Greeks 精算(见 9.5)**、活力监控、λ/GH、VPIN 反向信号、墓地金矿格。

## 9 · 公式表(实现以此为准)

> 约定:`dir`:多 YES=+1,多 NO=−1;价格单位 ¢;概率 p ∈ (0,1)。

### 9.1 定价与鞅
```
fair(t) = E[settle | F_t] × 100                    # settle ∈ {0,1}
鞅检验:  E[Δfair] = 0 (无条件)  且  E[Δfair | moneyness×tte 格] = 0 (条件)
σ_contract = |dP/dS| · σ_index · √τ                # 合约在 τ 秒内的正常晃动(¢)

# 条件鞅偏差 ⟺ 该格 σ 错(theta/gamma 抵消仅在 σ 正确时成立)
#   ⟹ 六指标 #2(σ比率)是 #1 的诊断辅助,不是独立指标
```

### 9.2 四段账(逐笔恒等式,兼生产断言)
```
fair_q ≜ fair(t_挂单, 冻结参数)
fair_f ≜ fair(t_成交, 冻结参数)         # 定义一次,两处共用(原版两处不同值 ⟹ 断言必红)

edge_quote = dir·(fair_q − price)
staleness  = dir·(fair_f − fair_q)
AS         = −dir·(settle − fair_f)

断言: dir·(settle − price) ≡ edge_quote + staleness − AS
fee = 实付(逐单取整),单列,不入恒等式

# 单列诊断,不进恒等式:
model_update = fair(t_成交, 实时参数) − fair_f
```

### 9.3 逆向选择
```
E[Δfair | 被成交] = Cov(Δfair, 1{成交}) / P(成交)      # E[Δfair]=0 时严格成立

MO(h) = dir·(参照(t_f + h) − 参照(t_f))                # 两端同一把尺子
        h ∈ {20,50,100,250,500ms, 1,2,5,15,30,60,120s, 结算}
        h < 1s  参照 = 币安隐含概率(见 9.6 前置校准)
        h ≥ 1s  参照 = Kalshi 中价
        h* = 实测撤单 RTT;MO(h*) 为头条(躲不掉的入场费)

对照组回归(全部报价时刻,未成交 = 天然对照 + 安慰剂):
        Δfair = α + β·1{成交} + γ·状态 + δ·(1{成交}×状态) + ε
        要求 α 的 CI 含 0;误差按市场窗聚类
        未成交样本数 ≥ 成交样本数 × 20,否则标 WEAK
```

### 9.4 漂移与检测
```
Δfair ≈ delta·ΔS + theta·Δt + 残差       # 检测只用 delta·ΔS 项
z = ΔS / (σ_index · √Δt)                 # 一切漂移阈值定义在 z 上,不用绝对 ¢
delta = [p(S+b) − p(S−b)] / (2b),  b = 0.1·σ_index·√τ
        # 数值差分,对任何定价形式都精确;固定 $1 bump 在临近结算会跳档失稳

# 盾的 gamma 偏差(单向,不可押后):盾用当前 delta 线性外推,
# 二元 delta 在行权价处最大 ⟹ 价格朝行权价移动时真实 Δfair 更大
# ⟹ 盾系统性反应不足,而那正是 fair 跑得最快、最该撤单的方向。
```

### 9.5 Greeks(**与我们的核匹配的加性形式**)
```
【纠正】原版写的 p = N(d2), d2 = ln(S/K)/(σ√τ) − σ√τ/2 是对数正态数字期权,
        与我们的核(算术平均/亚式 + 60s TWAP 锁定 + 正态加性结构)不匹配,不得直接接线。

加性核形式:
    p = Φ(d),   d = (S − K)/s,   s = σ_index·√(有效方差因子)
    有效方差因子:  锁定前  (τ − 60) + m(m+1)(2m+1)/6 / 60²
                   锁定中          m(m+1)(2m+1)/6 / 60²

    ∂p/∂s = −φ(d)·d/s
    ⟹ |vega| ∝ φ(d)·|d|,峰值在 |d| = 1  ⟹  p ≈ 16¢ 与 84¢
    ⟹ 高 vega 区 ≈ 5–35¢ 与 65–95¢;ATM 处 vega ≈ 0
    ⟹ σ 精雕预算按 |vega| 加权,重心在两翼不在 50¢

状态:数值 delta(9.4)为运行期唯一操作口径,已可用。
      闭式 vega/gamma 标 **理论待验证**,押后,不进施工主线。
```

### 9.6 币安参照的前置校准(**阻塞条件,非事后检查**)
```
接入 AS 主指标之前必须全部通过:
  ① 基差稳定性:币安隐含 − Kalshi 中价 的均值/漂移在窗口内可控
  ② 到达时间对齐:两侧时间戳用同一时钟基准,延迟分布已量化
  ③ 价格→概率映射误差:用 9.5 的加性核,误差随 σ 误差传播已估
  ④ 指数成分差异:RTI 为多所合成,币安为单所 —— 成分偏离已量化
  ⑤ 重叠区一致性:h = 1s、2s 处币安参照与 Kalshi 中价参照的 MO 差异 CI 含 0

任一不过 ⟹ 亚秒段 MO 只作探索性读数,不得进入 GATE-2 判决。
```

### 9.7 log-odds
```
L = ln(p/(1−p));  ΔL ≈ Δp/(p(1−p));  YES/NO 镜像 = 取负
taker费 7·p(1−p)¢ ≈ 0.07 L 单位        # 连续近似,非恒等式
                                        # clip=1 时逐单取整主导 ⟹ 一律用实付
跨行权价基础价差按恒定 ΔL 设,再换算回 ¢
```

### 9.8 库存经济学(**取代配对经济学**)
```
配对抽象(孤腿、45/90s 斜坡、让价上限、X_max = r/(1−r)·1¢、配对率 ≥75%)
是抽象的产物,不是经济现实。真实做市 = 连续双边报价 + 库存偏斜:

报价中心 = mid − q·γ·σ²·(T − t)          # A-S,库存自动卸载,无计时器无特殊出场路径
持仓上限: |q| ≤ q_max                    # 唯一的离散约束
τ_max ∝ (spread/(q·σ))²                  # 可容忍持仓时间,随库存平方衰减
edge_yes + edge_no ≡ spread;  双边同挂条件: spread > 2θ
clip ≤ 预算 / (k · 单笔最坏)              # k = 预设可承受连亏次数,按尾部不按均值

# 保留的事实:Kalshi 净额结算,q 回 0 时保证金即时释放。
#   但这是良好库存管理的结果,不是需要专门代码去追求的目标。
# 删除的副产品:孤腿会计科目及其独立执行路径
#   (今晚"三次判 sell_rich、零张发单"正是这条特殊路径造成的)。
```

### 9.9 估计与收缩
```
EB收缩: est = w·x̄ + (1−w)·μ_prior,  w = n/(n + σ²_格内/τ²_先验)
        先验只定符号/排序,幅度由自家样本定
毒性EWMA: α = 1 − 0.5^(1/halflife_fills)
聚类bootstrap: 重抽单位 = 市场窗口;有效 n ≈ 窗口数,不是笔数

所有估计返回 Est(value, sd)
half_spread = base + as.value + K·as.sd + skew
        ⟹ 薄格 sd 大 → 自动挂宽 → 自动少成交,不需要人判断"样本够不够"
```

### 9.10 归因检验
```
A0 包容: settle ~ a·logit(fair) + b·logit(mid)
         a ≈ 0 ⟹ fair 无增量信息,定价核判死
A  lead-lag(两版,见 5.3)+ Brier 分 tte 层
B  速度: staleness vs tape 平均 maker 同口径;反事实 = 撤单延迟 +X ms 重放的 PnL 差
C  选择: 我们的 MO(60s) − tape 平均 maker 的 MO(60s),同格量权汇总
D  税:  净 PnL 按先验税格/中性格分解

基准阶梯(成对差分,同时刻同市场):
   B0 傻做市(触价双边挂,无模型无闸无盾) → B1 +零费 → B2 +盾 → B3 +我们的 fair
   → B4 +闸门毒性 → B5 +库存偏斜
   每级增量 = 该层能力的归因
   各级增量之和 ≠ B5−B0 的差额 = 部件交互,必须报出
   B0 已为正 ⟹ 市场对任何被动报价者友好,我们的复杂度大部分是白加的
   B0 深负、B5 ≈ 0 ⟹ 我们在止血,不是赚钱
```

### 9.11 定价(GLFT,影子先行)
```
λ(δ) = A·e^(−kδ)                          # 从挂单历史拟合
d0 = sqrt(σ²γ/(2kA)) 系列闭式解见 glft_quotes.py(变量 delta 改名 offset_c)
half_spread(状态) = GLFT基础项 + E[AS|状态] + K·sd(AS|状态)
```
