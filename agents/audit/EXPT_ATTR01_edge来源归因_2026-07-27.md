# ATTR-01 · edge 来源归因:我们到底赢在哪

> Audit(Cowork Claude)· 2026-07-27 · 代号 **ATTR-01**(接 FLB-01 / AS-01 编号约定)
> 问题:「我们是赢在速度?赢在模型?我们的定价到底哪里更好?」
> **全部测试都在 tape 上跑,不需要开闸,不需要新数据。**

---

## 零、先把答案空间收窄:做市只有两种真 edge

结构上,被动报价者的优势只可能来自四处:

| 来源 | 性质 | 怎么验 |
|---|---|---|
| **① 知道价格更准** | **真 edge** | T1 · 预测力对决 |
| **② 反应更快** | **真 edge** | T2 · 延迟消融曲线 |
| ③ 零 maker 费 | **结构红利,不是本事** | 记账时单列,不许算进能力 |
| ④ 排队位置 | 执行质量 | T5 · 队列条件化 |

**所以"我们赢在哪"本质是个二选一,T1 和 T2 就能定调。其余测试是把答案拆细。**

---

## T1 · 我们的 fair 比市场中价更准吗(最根本,零成本)⭐

**如果我们的 fair 打不过市场中价,模型 edge 就是零,后面全部不用谈。**

**T1a · 记分对决**
用已结算市场,比较 `fair(t)` 与 `mid(t)` 对结算结果(0/1)的预测:
- **Brier 分数、log loss**,按 tte 分层;
- 全部 **out-of-sample**(参数封存日之后)。

**T1b · 预测包容检验(决定性的那一个)** ⭐
```
settle ~ a · logit(fair) + b · logit(mid)
```
- **a ≈ 0** → **我们的模型没有添加任何信息,它只是中价的一个噪声版本;**
- **a 显著 > 0 且 b 缩小** → **fair 里含有中价没有的信息,这才是模型 edge 的证据。**

这是预测评价里的标准做法(forecast encompassing),**比单看 Brier 强,因为它回答的是"增量信息",不是"谁分数高"。**

**T1c · 领先滞后**
`mid(t+h) ~ fair(t) − mid(t)`,h 取 100ms…5s。
**系数显著为正 = 我们的 fair 领先市场**,那是最硬的模型 edge 证据。**系数为零 = 我们只是跟随。**

**判据**:T1b 的 a 不显著 → **模型 edge = 0,应停止一切定价核调参,把资源全投到速度和选择上。**

## T2 · 速度值多少钱(延迟消融曲线)⭐

在 tape 回放里**人为注入延迟**:`0 / 5 / 10 / 25 / 50 / 100 / 250 / 1000 ms`,其余完全不变。

对每个延迟点报:**净 ¢/笔、成交/小时、¢/小时**。

- **曲线陡** → 速度是承重墙,**每减 1ms 值多少钱可以直接读出来,工程投入有了定价;**
- **曲线平** → **速度不是我们的 edge,别再往军备竞赛里投钱。**

**注意:这条曲线在既有验收标准里已经列为门条,但从未跑过。** 它同时给出 P0-1 那个"撤单延迟 h\*"的经济含义。

---

## T3 · 基准阶梯:每一级的增量就是那一层能力的归因 ⭐⭐

**这是对「我们赢在哪」最直接的回答。** 同一段 tape、同一批市场、同一套成交模型,只改一件事往上爬:

| 级别 | 配置 | 这一级的增量 = |
|---|---|---|
| **B0** | 永远在触价双边挂,无模型、无闸、无盾 | **基线:一个傻做市商在这个市场的下场** |
| **B1** | B0 + 零 maker 费口径 | **结构红利**(不是本事) |
| **B2** | B1 + 快锚盾 | **速度的贡献** |
| **B3** | B2 + 我们的 fair 定价 | **模型的贡献** |
| **B4** | B3 + 闸门与毒性表 | **选择性的贡献** |
| **B5** | B4 + 库存偏斜 / 配对 | **库存管理的贡献** |

**每一级报:净 ¢/笔、成交/小时、¢/小时(三个一起,防 Goodhart)。**

**两条方法学要求:**
1. **必须成对比较**——同一时刻、同一市场上两个配置各自的结果作差,**而不是两次独立运行比均值**。成对差分把共同的行情方差消掉,**有效样本量能提升一个量级;**
2. **增量不可加**——各级增量之和 ≠ B5−B0,差额就是**部件间的交互**。**两个数都要报,差额本身是信息**(例如盾和闸如果高度重叠,说明有一个是冗余的)。

**B0 这一级尤其重要:如果 B0 已经是负的,而 B5 只是没那么负,那我们不是在赚钱,是在少亏。**

---

## T4 · 留一消融:哪个零件是白装的

从完整系统开始,**每次只关掉一个**部件:盾 / 毒性表 / 2σ 上限 / 时区闸 / 库存偏斜。

报 `Δ(净 ¢/笔)` 与 `Δ(¢/小时)`,成对差分,聚类 CI。

- **关掉之后没变差的零件 = 白装的**,拆掉,减少一个会坏的地方;
- **T3 是"加上去值多少",T4 是"去掉之后损失多少"**,两者不一致的地方就是交互效应所在。

## T5 · 我们比"平均 maker"强在哪(接 AS-01 池 B)

AS-01 已经会算全市场每一笔被动成交的 markout。**在同样的格子里比我们自己的:**

- **我们更好** → 有执行/选择技能,**再用 T3 定位是哪一层给的;**
- **我们更差** → **别人在这里能活我们不能,问题在我们,不在市场。**

**队列条件化**:按下单时刻的 `queue_ahead` 估计值分组看 markout。
**排在前面的成交更干净 = 队列位置是承重变量**,那么"改善报价 0.1¢ 换队首"就有了可计算的价格。
(**前提:成交现场快照里要记 queue_ahead——现在没记,先补上,否则这一项永远做不了。**)

## 统一报表格式(所有测试共用)

每一行必须同时给出:

```
净 ¢/笔  |  成交/小时  |  ¢/小时  |  有效 cluster 数  |  95% CI(按市场聚类 bootstrap)
```

**三个指标必须并排,任何一个都不许单独当 KPI。**
理由:压 AS 最简单的办法是不成交;提准度最简单的办法是只在安静盘报价。**真目标永远是乘积。**

## 优先级(按 决定性 ÷ 工程量)

1. **T1b · 预测包容检验** —— 零成本,**而且可能一次性判掉整条模型线**;
2. **T3 · 基准阶梯** —— 直接回答本文标题,工程量中等,**B0 基线尤其必须先跑**;
3. **T2 · 延迟曲线** —— 给速度投资定价,验收标准里早就该跑;
4. **T4 · 留一消融** —— 找白装的零件;
5. **T5 · 队列** —— 需要先补 `queue_ahead` 字段。

## 预先声明的可能结论(写在前面,防止事后挑好看的说)

- **T1b 的 a ≈ 0 且 T2 曲线平** → **我们既不更准也不更快,现在的正收益(若有)全部来自零费和运气。** 这是一个完全可能的结果,**必须允许它被说出来;**
- **T3 显示 B0 已为正** → 这个市场对任何被动报价者都友好,**我们的复杂度大部分是白加的;**
- **T3 显示 B0 深负而 B5 接近零** → **我们做的是止血,不是赚钱。**
