**铁律:`core/` 不许 import 任何做 I/O 的东西。** CI 加一条静态检查,违反即失败。
**理由**:今晚"影子 5494 次评估 / 实盘 0 次"是两条代码路径分叉的代价。**纯核 + 单一路径,这类事故在结构上消失。**

## 2 · State:唯一的决策输入契约 ⭐

**决策只允许依赖 State 里的字段。读了 State 之外的东西 = bug。**

```python
@dataclass(frozen=True)
class State:
    # 时间
    t_ns: int
    tte_s: float
    # 标的
    anchor_px: float          # 快源(币安)
    anchor_age_ns: int        # 陈旧度,必须显式
    rti_px: float
    rti_age_ns: int
    locked_sum: float         # TWAP 锁定累积
    locked_n: int
    # 合约
    strike: float
    # 盘口
    yes_bid_c: int
    yes_ask_c: int
    bid_qty: int
    ask_qty: int
    queue_ahead_bid: int      # ← 现在没记,必须补(T5 依赖它)
    queue_ahead_ask: int
    # 流
    taker_imbalance: float    # 近窗 taker 方向失衡
    volume_bucket_pos: float  # 量钟位置(VPIN 候选维,暂不接报价)
    # 我们
    q: int                    # 净库存,带符号
    # 波动
    sigma_fast: float
    sigma_slow: float
```

**三个副产品,全部免费:**

1. **成交现场快照 = 直接序列化 State**,不用事后拼接;
2. **回放保真 = 重放 State 序列**,不需要模拟器复刻世界;
3. **`quote(State) → Quote` 可做位级一致性测试**(见 §7)。

## 3 · 带不确定度的返回值 ⭐

```python
@dataclass(frozen=True)
class Est:
    value: float
    sd: float                 # 该估计自身的标准差
```

**所有估计函数返回 `Est`,不返回裸 float。**

**用法(这是"不确定就挂宽"的具体机制):**

```python
half_spread = base + as_est.value + K_UNCERT * as_est.sd + skew
```

**EB 收缩之后,数据薄的格子 sd 大 → 自动挂宽 → 自动少成交。**
**数据厚了 sd 收窄 → 自动收紧抢队列。**
→ **不需要任何人手动决定"这个格子样本够不够",样本量自己说话。**

## 4 · 核心函数签名

### 4.1 定价(`core/pricing.py`)

```python
def fair(s: State, p: Params) -> Est
    """条件概率,¢。锁定期用 locked_sum/locked_n,未锁用全窗方差。"""

def delta_c_per_usd(s: State, p: Params) -> float
    """中心差分,bump = 0.1 * sigma_fast * sqrt(tte_s) * anchor_px。
       禁止固定 $1 bump —— 临近结算 p(S) 近阶跃,固定 bump 会跳档失稳。"""

def sigma_fast(ticks) -> float      # 300s 窗,用于定价
def sigma_slow(hist) -> float       # ≥6h 滚动中位数,用于一切"离谱判定"
```

**慢/快 σ 必须是两个函数、两个字段,不许复用同一变量**(砸盘时快 σ 会给异常本身发通行证)。

### 4.2 逆向选择 —— 唯一真理源(`core/adverse.py`)⭐

```python
def as_estimate(s: State, p: Params) -> Est
    """E[AS | 状态],¢/张。
       连续自变量: moneyness(log-odds 或 d) × tte
       离散自变量: taker 方向
       允许断裂点: 50¢、墓地边界(实测符号翻转处)
       输出经 EB 收缩,sd 反映格内样本量。"""
```

**现在的时区闸 / 2σ 上限 / 毒性表 / 盾,四段代码估的都是这一个量。**
**它们必须全部并入本函数,或作为它的输入特征。不许再有第二个地方回答"这笔危不危险"。**

盾的角色变了:**盾不再是独立闸门,而是给 `as_estimate` 提供 `anchor_age_ns` 和锚移动特征的输入源**;它对报价的影响通过 half_spread 体现。

### 4.3 报价(`core/quoting.py`)

```python
def half_spread(s: State, p: Params) -> Est
    """= base(ΔL 恒定) + as_estimate + K*sd + inventory_skew"""

def quote(s: State, p: Params) -> Quote | None
    """None 时必须携带 reason(见下)。"""
```

```python
class BlockReason(Enum):
    SPREAD_INSUFFICIENT   # half_spread > 可用点差 —— 这就是旧"闸门"
    GRAVEYARD             # 硬闸(结算真值,非策略偏好)
    INVENTORY_CAP
    STALE_ANCHOR
    HALT
```

**关键设计:闸门不再是独立代码,而是定价的退化解。**
**所有拦截走同一个 `BlockReason` 枚举 → 归因计数天然穷尽,不会再出现"64/66 被拦却没人知道"。**

### 4.4 库存与孤腿(`core/inventory.py`)

```python
def inventory_skew(s: State, p: Params) -> float
    """A-S: q * gamma * sigma^2 * (T-t),报价中心偏移。"""

def orphan_max_concession(pair_rate_observed: float) -> float
    """X_max = r/(1-r) * 1.0¢   ← 公式,不是常数 3
       r 取近窗实测配对率;r < 0.5 时返回 <1¢。"""

def exit_action(pos, s: State, p: Params) -> Action
```

**`Action` 必须包含 `post_only=True` 且**:

```python

# post-only 不保证成交,行情跑过即抱到结算,真实亏损无上限。
max_concession_c: float
```

## 5 · 参数 artifact(取代 20 多个 `MM_*` 环境变量)⭐

```python
@dataclass(frozen=True)
class Params:
    version: str
    sha256: str
    fitted_at: str
    train_window: tuple[str, str]      # 出处
    as_model: ...                      # 系数
    prior_grid: ...                    # 大盘先验(只定符号/排序)
    eb_hyper: ...                      # tau^2 等
    base_spread_dL: float
    k_uncert: float
    gamma: float
```

**规矩:**

- **运行期只读,永不写;**
- **每条收据带 `params.sha256`** —— 任何结果都能追到参数版本;
- **artifact 进版本库,回滚是一条命令**(今晚"本地修了 EC2 没修""SHA 对了但闩锁还在"都是没有这一层的症状);
- **环境变量只保留真·运行配置**(端点、路径、开关),**模型参数一个不留。**

## 6 · 离线估计模块(`estimation/`)

```python
# control_regression.py
#   Δfair = α + β·1{成交} + γ·状态 + δ·(1{成交}×状态) + ε
#   在所有报价时刻上跑(未成交时刻 = 天然对照 + 安慰剂)
#   α ≈ 0 内嵌鞅检验;δ = 毒性函数
#   误差:市场窗聚类 bootstrap
def fit_adverse(quotes, fills, marks) -> AsModel

# martingale.py
#   条件版:按 (moneyness × tte) 分格 E[Δfair|格] ≈ 0
#   非零格 = 该格 σ 错(theta/gamma 抵消仅在 σ 正确时成立)
#   → 输出"定价 bug 清单",按 |vega| 加权排序(vega 在两翼最大,不在 50¢)
def martingale_report(fair_series) -> CellReport

# shrinkage.py
#   w = n / (n + sigma^2/tau^2)，逐格自适应
def shrink(cell_mean, cell_n, cell_var, prior) -> Est
```

**输出统一为一个 `Params` artifact,由 CI 打哈希。**

## 7 · 测试(每条对应一具尸体)

| 测试 | 内容 | 对应事故 |
|---|---|---|
| **纯度** | 同一 State 在 shadow/live/replay 三条路径产出**位级相同**的 Quote | 影子 5494 / 实盘 0 |

| **单调性** | as↑ ⟹ half_spread↑;q↑ ⟹ 报价中心下压;σ_slow↑ ⟹ 上限**不**放宽 | 慢σ反常性 |

## 8 · 迁移路径:绞杀式,不要大爆炸重构 ⭐

**在实盘运行中做全量重构 = 今晚事故的放大版。** 分四步:

1. **建 `core/` 与 State,不接线** —— 现有引擎在每次评估时**额外**构造一个 State 并调用新 `quote()`,**结果只记录不使用**;
2. **对比期**:记录 `新Quote vs 旧决策` 的逐笔差异,跑够一整天。**差异必须每一条都能解释**,不能解释的先查清;
3. **影子切换**:影子实例改用 `core/`,实盘仍走旧路;两者并排,比 ¢/笔与拦截分布;
4. **实盘切换**:仅当第 3 步在预注册窗口内不劣于旧版。**旧代码保留一次回滚周期后再删。**

**每一步都可回滚,任何一步失败不影响钱闸状态。**

## 9 · 施工顺序(对齐 MATH_SPEC 的 W1/W2/W3)

**W1 · 照明(不改行为)**
State + 现场快照 + `queue_ahead` 补字段 → `ledger.split` + 闭合断言 → `BlockReason` 穷尽计数 → 存活断言。
**本周不动任何决策逻辑,只让账目和拦截可见。**

**W2 · 裁决(离线,不碰实盘)**
`control_regression` → 条件鞅检验(按 |vega| 加权读) → EB 收缩产出首版 `Params` artifact → 预测包容检验 `settle ~ a·logit(fair)+b·logit(mid)`(零成本 kill-test,**放最前**)。

**W3 · 定价(替换闸门)**
`as_estimate` 合并四段闸 → `half_spread` 接线 → 绞杀式迁移 §8 四步 → ATTR-01 基准阶梯 B0–B5。

**押后**:延迟反事实回放、vega/gamma 精修(墓地开闸前)、VPIN 反向信号(等样本外)、λ/GH。
