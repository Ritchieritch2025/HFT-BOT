# 口径规格:edge / 漂移 / 协方差 怎么算

> Audit(Cowork Claude)· 2026-07-27 · **地基文件,不是策略文件**
> 目的:把"我们赚多少、被吃掉多少、怎么估"三件事的定义钉死,**让所有实验、回执、报表用同一套记账**。
> 现状问题:同一个"edge"这个词,在报价时、成交时、结算时指的是三个不同的量,现在混着用。

---

## 一、fair 的性质:鞅,以及一个免费的模型体检

`p_t = P(结算价 > 行权价 | t 时刻信息)`。**若定价核正确,p 是鞅**:`E[p_{t+h} | F_t] = p_t`。

推论,而且是可检验的:

**无条件漂移的期望必须是零。**

- **躲漂移是没有意义的**——它是介质,不是敌人;
- **如果我们在数据上测出 fair 有显著的无条件漂移,那不是机会,是定价核错了**(σ 口径、锁定项、或 delta 换算)。

**立刻可做的免费体检**:拿全部历史 fair 序列,检验 `E[Δp] = 0`,分 tte 分层。
**这是我们从没做过的模型自检,零成本,而且它是后面一切估计的前提**——**fair 不是鞅,AS 的整个定义就塌了。** 放进 AS-01 的健全性检验作为第 5 条。

## 二、一笔成交的三段分解(核心:现在被混成一个数)

对一笔挂单:t₀ 挂出,t₁ 成交,t₁+h 观察。

```
总实现 = [ fair(t₁) − P_fill ]        ← ① 成交瞬间真正拿到的边际
       + [ fair(t₁+h) − fair(t₁) ]    ← ② 成交之后的逆向选择
另外单独记:
陈旧损失 = fair(t₁) − fair(t₀)         ← ③ 挂单期间 fair 跑掉了多少
```

**三个数,三种病,三种药,现在全叫 "edge":**

| 分量 | 含义 | 对应的药 | 现在的状态 |
|---|---|---|---|
| ① 成交瞬间边际 | 报价位置选得好不好 | 报价位置 / 队列 | 有(但用的是 t₀ 的 fair,错) |
| ② 成交后漂移 | **逆向选择本体** | 状态定价(价差随毒性变宽) | **从未测过** |
| ③ 陈旧损失 | 挂单在那儿变馊了 | **撤单延迟 / 快锚盾** | 从未单独记 |

**硬要求:`edge_entry` 现在用的是挂单时刻的 fair,必须改成成交时刻的 fair。** 两者之差就是 ③,**它是盾的绩效指标,而不是应该被吸进 ① 里的东西。**
**没有这个拆分,盾做得好不好永远说不清。**

## 三、逆向选择的精确形式:一个协方差除以成交概率

因为 `E[Δfair] = 0`:

```
AS(状态) = E[ −Δfair | 被成交, 状态 ]
         = −Cov( Δfair , 1{被成交} | 状态 ) / P(被成交 | 状态)
```

**这个式子有两个直接可用的推论,第二个我们从没利用过:**

**推论 1**:AS 的来源不是"市场动",是**成交时刻在时间轴上不是随机采样**——它们扎堆在信息正在被消化的那几秒。所以**降 AS 只有两条路:降协方差,或提高分母。**

**推论 2(未被利用)**:**分母是可以主动做大的。** 在良性状态里多挂、多成交,**在协方差完全不变的情况下也会稀释 AS。**
→ **"少挂单"不是防御的唯一形态,"在安全的地方多挂"是同一个式子的另一半。** 这正好回应"闸门只会让我们少挂单"那个不适感:**统一到定价之后,防御和进攻是同一个连续量的两端。**

## 四、估计量设计(四条,按重要性)

### 4.1 用未成交的报价做对照,不要只看成交 ⭐

现在的做法是只在成交样本上取平均——**丢掉了绝大部分信息,而且无法把"选择"和"漂移"分开。**

更好的估计量:在**所有报价时刻**(成交的和没成交的)上做回归

```
Δfair(t, h) = α + β · 1{被成交} + γ' · 状态 + δ' · (1{被成交} × 状态) + ε
```

- **α 必须 ≈ 0**(鞅检验,即第一节的体检,也是安慰剂对照);
- **β = 平均逆向选择**;
- **δ = 状态条件下的逆向选择,即毒性函数本体。**

**未成交的报价是天然对照组,数量是成交样本的几十上百倍。** 这一步把有效样本量提升一个量级,**且不需要任何新数据。**

### 4.2 别再切格子,用连续函数 ⭐

56 个 `方向 × 价区 × 时段` 的格子,**在 300 笔自有成交下永远填不满**——今天已经出现"两维条件化撑不住、单格 n=20"的症状。

**今早 FLB-01 的同一个教训,换了个地方重演:格子是路标,不是真理。**

改法:把价区和 tte 当**连续变量**进模型(样条 / 单调回归),**只保留天然离散的维度(taker 方向)。** 连续模型在格子之间借力,**不会因为某一格样本少就给出 ±19¢ 的荒唐数值。**

### 4.3 先验权重上限 100 → 换成经验贝叶斯收缩 ⭐

"上限 100"是**手工设定的收缩强度**,方向对,但数值是拍的。

正确形式:**分层模型 / James-Stein 收缩**,收缩权重由方差比自动决定

```
w_prior = τ²_组间 / ( τ²_组间 + σ²_格内/n_格 )
```

**格内样本少、噪声大 → 自动更靠先验;样本多 → 自动更靠自己。** 每个格子的权重各不相同,**不需要任何人拍一个 100。**

这同时干净地解决了"300 万大盘先验 vs 几百笔实盘"的张力,**而且把它从一个可争论的旋钮变成了一个可推导的量。**

### 4.4 方差估计:聚类 + 重叠窗

- **长 h(≥30s)按市场聚类**;
- **短 h(<5s)按 (市场 × 10 秒桶) 聚类**;
- markout 窗口互相重叠 → **必须用 block bootstrap 或 cluster-robust,不许用 iid 标准误**;
- **n 一律报"有效 cluster 数",不报笔数。**(RC-2 教训:按笔算会把 n 虚增几十倍。)

## 五、单位与比较基准(全项目统一)

- **一切以 ¢/张 计**,不用百分比、不用美元、不用"每市场";
- **比较基准恒为 0.5¢**(1¢ 点差的单边毛空间,maker 费 0);
- 任何报表里的 edge / AS / markout **必须同时标注:哪一段(①②③)、哪个 h、哪把尺子、有效 cluster 数。**
- **缺任一项的数字,视为不可引用。**

## 六、大盘先验的使用纪律(两条硬规矩)

那 300 万样本测的是**平均在场 maker 的遭遇**——带着他们的队列位置和撤退技术。

1. **先验只提供格子的符号与相对排序,不提供加价的绝对幅度。** 绝对量只能由自有实盘样本(经 4.3 的收缩)决定。**防止某个"历史 +19¢"直接变成报价参数;**
2. **任何来自先验的数值进入报价前,必须先在影子里跑过,并且在 AS-01 的框架下重算过置信区间。**

## 七、落地顺序

1. **鞅体检**(§1)——零成本,是一切的前提,**先跑**;
2. **三段分解接线**(§2)——把 `edge_entry` 改用成交时刻 fair,并单独记 ③;
3. **回归估计量**(§4.1)——用未成交报价做对照,样本量立刻上一个量级;
4. **连续化 + 收缩**(§4.2 / 4.3)——替换格子与手拍权重;
5. 之后再谈把"拦"升级成 Glosten-Milgrom 式的 **fair 对成交做条件更新**。

**前四步都不需要新数据,也不需要开闸。**
