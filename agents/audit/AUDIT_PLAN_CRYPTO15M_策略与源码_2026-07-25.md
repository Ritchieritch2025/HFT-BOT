## A — 经济基础(排序1,最高优先)

| # | 问题 | 测试 | 判据 |
|---|---|---|---|
| A-1 | maker 费真的是 0 | 取在档 372 笔成交 / $954 中的 crypto 子集,逐笔用交易所账单对账 maker 费栏;**不接受**仅凭费率表 PDF 结论 | crypto 子集 ≥10 笔实测 maker 费恰为 0 → 通过。任一笔非 0 → **策略死**,立即停研究 |
| A-2 | 0.311¢/张 的口径与可复现性 | 索取回放脚本 + 随机种子 + TRAIN/TEST 切分定义;独立重跑 | 复现值与 0.311 差 < 0.02¢,且 TEST 集在时间上严格晚于 TRAIN(无前视) |
| A-3 | 0.311¢ 是否建立在有洞的带子上 | 交叉 L2 逐窗口覆盖表与回放所用窗口清单 | 回放窗口 100% 有 L2 覆盖;否则重算并报覆盖率加权后的边际 |
| A-4 | 边际 vs 成本的余量 | 用 A-1 实测费 + 实测滑点重算净边际 | 净边际 CI 下界 > 0(预注册 §3:`μ_lo ≤ 0 ⇒ 不部署`,这是开关不是参数) |
| A-5 | 吞吐量与规模现实性 | 878s 挂牌、tte≥600s 闸 → 全价区带宽仅 **278s/窗**;96 窗/日 × 2 侧 × CLIP | 复算日成交笔数期望是否落在预注册 §2 的 20–60 笔;并报日毛收益量级 |

**A-5 复算参考(审计侧须独立验算,勿抄):**
96 窗/日 × 2 侧 × 2 张 = 384 张/日;× 0.311¢ ≈ **$1.19/日毛**(占 $200 约 0.6%/日)。
量级本身不是否决理由,但它决定:**任何每笔固定成本都是致命的**,且 P0-2 的 $8 不释放上限
在跨窗口维度直接封顶总成交数。请核对这两条推论。
