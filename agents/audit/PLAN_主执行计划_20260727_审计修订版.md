## 公式表(实现以此为准,dir: 多YES=+1,多NO=−1,价格单位¢,概率p∈(0,1))

### 定价与鞅
```
fair(t) = E[settle | F_t] × 100          # settle ∈ {0,1}
鞅检验:   E[Δfair] = 0 (无条件)  且  E[Δfair | moneyness×tte 格] = 0 (条件)
σ_contract = |dP/dS| · σ_index · √τ
# 注:条件鞅偏差 ⟺ 该格 σ 错(theta/gamma 抵消仅在 σ 正确时成立)
#     ⟹ 六指标 #2(σ比率)是 #1 的诊断辅助,不是独立指标
```

### 四段账(逐笔恒等式,兼代码断言)
```
【改】原版 staleness 用"冻结参数"版 fair,AS 用未限定版 fair —— 两个不同的值,
      望远镜叠不掉,生产断言必红,然后会有人去放宽容差(=废掉这条断言)。

fair_q ≜ fair(t_挂单, 冻结参数)
fair_f ≜ fair(t_成交, 冻结参数)          # 定义一次,两处共用

edge_quote = dir·(fair_q − price)
staleness  = dir·(fair_f − fair_q)
AS         = −dir·(settle − fair_f)
断言: dir·(settle − price) ≡ edge_quote + staleness − AS     # fee 两边同减,不入恒等式
fee = 实付(取整后),单列

# 单列诊断,不进恒等式:
model_update = fair(t_成交, 实时参数) − fair_f
```

### 逆向选择
```
E[Δfair | 被成交] = Cov(Δfair, 1{成交}) / P(成交)      # E[Δfair]=0 时严格成立

【改】MO 两端必须同一把尺子,否则模型与市场的水平差混入,h→0 时不收敛到 0,头条数字被污染。
MO(h) = dir·(参照(t_f + h) − 参照(t_f))
        h ∈ {20,50,100,250,500ms, 1,2,5,15,30,60,120s, 结算}
        h < 1s 参照 = 币安隐含概率(连续,无 tick 限制)
        h ≥ 1s 参照 = Kalshi 中价
        两把尺子在 h=1s、2s 必须给出一致读数,否则换算有误
        h* = 实测撤单 RTT,MO(h*) 为头条

【改】原版漏了状态主效应,交互项会把"该状态下 fair 本就在动"吸成"该状态的流有毒"。
对照组回归: Δfair = α + β·1{成交} + γ·状态 + δ·(1{成交}×状态) + ε
        全部报价时刻(未成交 = 天然对照 + 安慰剂)
        要求 α 的 CI 含 0;误差按市场窗聚类
        未成交样本数 ≥ 成交样本数 × 20,否则标 WEAK
```

### 漂移与检测
```
Δfair ≈ delta·ΔS + theta·Δt + 残差       # 检测只用 delta·ΔS 项
z = ΔS / (σ_index · √Δt)                 # 一切漂移阈值定义在 z 上,不用绝对¢
delta = [p(S+b) − p(S−b)] / (2b),  b = 0.1·σ_index·√τ   # 中心差分,自然尺度 bump

# 盾的 gamma 偏差(单向,不可押后):盾用当前 delta 线性外推,
# 而二元 delta 在行权价处最大 ⟹ 价格朝行权价移动时真实 Δfair 更大 ⟹ 盾系统性反应不足,
# 且那正是 fair 跑得最快、最该撤单的方向。
```

### Greeks(二元)
```
p = N(d2),  d2 = ln(S/K)/(σ√τ) − σ√τ/2
vega = n(d2)·∂d2/∂σ

【改】|vega| 极大化 n(u)·|u| ⟹ |d2| = 1 ⟹ p ≈ 16¢ 与 84¢

```

### 【改】库存经济学(取代原"配对经济学")
```
原版整套配对机械(孤腿、45/90秒斜坡、让价上限、X_max = r/(1−r)·1¢、配对率≥75%)
是"配对"这个抽象造出来的产物,不是经济现实。真实做市是连续双边报价 + 库存偏斜:

报价中心 = mid − q·γ·σ²·(T−t)                # A-S,库存自动卸载,无计时器无特殊出场路径
持仓上限: |q| ≤ q_max                         # 唯一的离散约束
τ_max ∝ (spread/(q·σ))²                       # 可容忍持仓时间,随库存平方衰减
edge_yes + edge_no ≡ spread;  双边同挂条件: spread > 2θ
clip ≤ 预算 / (k·单笔最坏)                     # k = 预设可承受连亏次数,按尾部不按均值

# 保留的事实:Kalshi 净额结算,q 回到 0 时保证金即时释放。
# 但这是良好库存管理的"结果",不是需要专门代码去追求的"目标"。
# 删除的副产品:孤腿这个会计科目、它的独立执行路径
#   (今晚"三次判 sell_rich、零张发单"正是这条特殊路径造成的)。
```

### 估计与收缩
```
EB收缩: est = w·x̄ + (1−w)·μ_prior,  w = n/(n + σ²_格内/τ²_先验)   # 先验只定符号/排序
毒性EWMA: α = 1 − 0.5^(1/halflife_fills)
聚类bootstrap: 重抽单位 = 市场窗口; 有效 n ≈ 窗口数,不是笔数

   ⟹ 薄格 sd 大 → 自动挂宽 → 自动少成交,不需要人判断"样本够不够"
```

### 归因检验
```
A0 包容: settle ~ a·logit(fair) + b·logit(mid);  a≈0 ⟹ fair 无增量信息,定价核判死
A  lead-lag(两版):
     Δmid(t→t+h) = β·(fair − mid)(t)        # 我们的模型领不领先
     Δmid(t→t+h) = β·(币安隐含 − mid)(t)     # 【新】信息路径的领先存不存在(绕开自家模型)

D  税:  净 PnL 按先验税格/中性格分解

【新】基准阶梯(ATTR-01),成对差分(同时刻同市场):
   B0 傻做市(触价双边挂,无模型无闸无盾) → B1 +零费 → B2 +盾 → B3 +我们的fair

```
