## 一、唯一的问题(可证伪)

**在我们自己的结算真值上,按市场族分层后,哪些族、哪些价格桶存在"标价 vs 实际兑现率"的系统性偏差?幅度多大?扣掉双边成本后还剩不剩?**

注意三个必须分开的问题,过去被混为一谈:
1. **偏差存不存在**(描述性,只需结算真值);
2. **偏差是错价还是风险溢价**(需要跳空事件的样本);
3. **偏差能不能被我们收割**(需要成本+仓位约束)。

本实验只回答 ①,并为 ② 收集判据。**③ 明确不在范围内。**

---

## 二、分层维度(操作员原则：禁止跨族混池)

**第一层 · 市场族(硬分层,结论永不合并)**

| 族 | 说明 | 为什么必须分开 |
|---|---|---|
| crypto 15M(KXBTC15M/KXETH15M) | 15 分钟二元 | 结算=RTI TWAP,无"内幕",纯波动 |
| crypto 小时(KXBTCD/KXETHD/KXBTC/KXETH) | 阶梯/阈值 | 同标的但视界长 6-60 倍 |
| 体育-单场(KXMLBGAME 等) | 比赛结果 | 有比赛进程信息,存在实时知情流 |
| 体育-道具(RBI/篮板/PGA 等) | 球员表现 | 结算机制、参与者完全不同 |
| 政治/事件 | 选举、提及 | 长视界、低频、结算规则复杂 |
| 经济数据 | CPI/FED | 定时发布,信息结构独特 |

**第二层 · 价格桶**：1-5 / 5-10 / 10-20 / 20-35 / 35-50 / 50-65 / 65-80 / 80-90 / 90-95 / 95-99¢
(两端更细,因为文献说偏差集中在极端)

**第三层 · 距结算时间**：>60m / 10-60m / 5-10m / 2-5m / <2m
(临近结算时价格已收敛,偏差应自然消失——这是内建的合理性检验)

## 三、数据与口径

- **价格取值**：每笔成交的实际成交价(不是 mid,不是收盘价)——**这是"参与者实际付了什么"**;
- **兑现率**：该价格桶内全部合约的真实结算结果均值(0/100),来自 catalog_normal 已验证结算记录;
- **样本单位**：**市场(market),不是成交笔数**。同一市场内所有成交共享同一个结算结果,按笔计算会把 n 虚增几十倍(RC-2 那次的教训);
- **时间范围**：全部已封存日,不做 8+4 切分(本实验是描述性测量,不是策略选参)。

---

## 四、必须同时报告的四个数(缺一不可)

每个 (族 × 价格桶 × 时段) 格子报：

1. **n_markets**(独立市场数)——**<30 的格子标灰,不给结论**;
2. **平均成交价** vs **实际兑现率**,及其差值(百分点);
3. **95% CI**(按市场做 cluster bootstrap ×1000);
4. **该格子的双边成本**(点差 + taker 费),用于回答"偏差是否超过摩擦"。

---

## 五、三个预先声明的健全性检验(不过就说明数据或口径有问题)

1. **收敛性**：同一族内,**距结算 <2m 的格子偏差必须显著小于 >60m 的格子**。价格临近结算必然收敛,若不收敛 = 数据有问题;
2. **互补性**：YES 侧 p 桶的偏差,应与 NO 侧 (100−p) 桶的偏差**符号相反、幅度相当**。不满足 = 口径错(很可能又是方向/字段问题);
3. **零假设格**：50±5¢ 的格子偏差应≈0(那里没有冷门/热门之分)。若这一格也系统性偏,说明存在与 FLB 无关的系统性误差,先查那个。

---

## 六、为"错价 vs 风险溢价"收集的判据(不下结论,只记录)

- **跳空事件清单**：窗口内标的价格跳变超过 X σ 的事件,逐个记录发生时间与所在市场;
- **每个格子的最大单次损失**(若做空该格,最坏一次赔多少);
- **判据**：若冷门格的"高估幅度"与"跳空事件的期望损失"同量级 → 倾向风险溢价;若高估幅度显著更大 → 倾向真实错价。
- **明确写死**：样本中出现的显著跳空事件 <3 次时,**此判据不成立,不许下结论**。

## 七、方法学(照抄 Wolfers-Zitzewitz 的三条,一条自研)

**W-Z 原文做法**：全美 1992-2002 全部赛马,5,067,832 次出赛 / 611,807 场比赛,零筛选;度量"每投 1 美元的回报率"(抽水内含);横轴 log odds;95% CI 带随样本厚薄变宽;**聚类单位是"比赛"不是"出赛"**(同场只有一匹能赢,结果机械相关)。

照抄:
1. **主度量 = 每美元净回报**(点差+手续费内含),不用"百分点偏差"——**成本自动包含,一眼可读盈亏平衡**;
2. **横轴 log odds**,不用等宽价格桶;
3. **聚类单位 = 市场**(他们的"比赛"就是我们的"市场":同一市场所有成交共享同一个结算结果)。

自研(因为我们和赛马有一个关键差异):
4. **赛马场抽 17% 水,他们图上所有赔率的回报都是负的,FLB 只是相对概念;我们挂单零费,所以盈亏平衡线是真的可能被跨过去的。** 主图必须画出这条线,并明确标注哪些格子在线上方。

**主判据(不依赖任何分桶)**：**log-odds 校准回归的斜率**。市场校准良好 → 斜率=1;**冷门高估(FLB)的数学签名是斜率<1**。分族各报一个斜率 + 置信区间。分桶表降级为展示用。

## 八、这个实验为什么值得先做

- **零成本**(数据全在手)、**零风险**(纯只读);
- 它同时服务多条线：crypto MM 的价区选择、体育道具盘的老结论复核、政治校准测试(卡了两周的那个);
- **它是我们第一次用自己的大样本去检验一个跨市场文献规律**——不管结果支持还是推翻,都是可靠的地基;
- 若某族某桶的偏差显著超过成本且样本充足,那才是下一个候选策略的起点——**但那是另一个实验,不是这个。**
