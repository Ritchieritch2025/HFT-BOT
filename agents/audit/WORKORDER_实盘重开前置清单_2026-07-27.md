# P0 · 开闸前必须完成(缺一不开)

## P0-1 · 2σ 入场上限改用慢 σ

**问题**:`MM_MAX_EDGE_SIGMA=2.0` 用的是定价那条快 σ(300 秒窗)。**砸盘时 σ 上升 → 2σ 阈值变宽 → 这道闸在最该收紧的时刻最松。** 它防的正是砸盘接刀,而它在砸盘时失效。

**要求**:
- 上限的 σ 换成**慢基准**:该市场族 σ 的滚动中位数(建议 ≥6 小时窗),或固定分位数;**定价仍用快 σ,两者分开取值,不复用同一个变量**;
- 再加一道**绝对分上限**做兜底(建议 8¢,可调),防止慢 σ 本身在高波动期整体抬升;
- 单元测试必须含一条:**构造"σ 突然翻倍"的输入,验证上限阈值不随之放宽。**

## P0-2 · 四道闸的归因计数器

**问题**:今夜同时改了四件事,**没有任何计数器,结果无论好坏都归因不了。** 其中"开中间区"是在推翻 E2 的 6.1 亿张合约旧结论,**它必须能被单独证伪。**

**要求**:每次评估落一条结构化记录,至少含:

| 计数项 | 含义 |
|---|---|
| `gate_zone_admit` / `gate_zone_block` | 时区闸放行/拦截(区分墓地硬闸与中间区) |
| `gate_maxedge_block` | 2σ 上限拒绝入场 |
| `shield_cancel` | 快锚盾撤单次数 |
| `orphan_open` / `orphan_paired` / `orphan_settled` | 孤腿产生 / 事后配上 / 抱到结算 |

- dashboard 上单独一块显示这六个数;
- **每小时汇总一条收据落盘。**

## P0-3 · 2σ 拒单的反事实记录

被 2σ 拦下的机会不许无声丢弃。**每次拒绝落一条:市场 / 时间 / 当时挂价 / 公允价 / edge / 该市场最终结算结果。**

理由:这道闸是全新判据,**没有任何实盘证据支持 2.0 这个数**。有了反事实记录,一周后可以直接算出"如果没这道闸,那些单赚还是亏",**把一个拍脑袋的常数变成可校准的参数。** 成本为零。

## P0-4 · 孤腿 maker 退出执行管道

**问题(第三次提出,仍未做)**:`position_reval()` 会判 `sell_rich`,**但没有任何部件执行它**——07-27 07:51 连续三次判定出货、发单 0 张。盲砍闹钟已关,**所以现在孤腿的唯一归宿是抱到结算 = 一次方向赌博**,而操作员明确要求不赌方向。

**且今夜的改动会放大这个洞**:中间区解禁 → 成交增多 → **孤腿绝对数增多。**

**要求**:
- 判断层产出 `sell_rich` / `buy_cheap` 后,**执行层挂反向 maker 单**(不许 IOC、不许穿点差);
- 挂价、改价、撤单全部走 maker;**任何 taker 出场必须显式开关控制,默认关闭**;
- 挂出后进入正常重估回路,价格变了要能改价;
- **落一条 `EXIT_SENT` 收据**,含判断时刻 → 发单时刻的延迟。

## P1-1 · 本轮的预先判据

开闸前把下面三条写进收据,**事后不许调整**:

- **配对成功率 ≥75%** —— 低于此,1¢ 锁差的算术不成立(见下);
- **孤腿平均成本 < 3¢** —— 生死线由 `0.75×1¢ = 0.25×X → X=3¢` 推出;累计 **≥30 根孤腿**后判定;

**任一条不满足 → 配对模式判负,不允许"再调调看"。**

## P1-2 · 孤腿成本计量器做成一等公民

每根孤腿一条记录:发生时间 / 配不上的原因 / 最终处理方式(maker 退出 / 抱到结算)/ 相对当时 fair 的成本 ¢ / 是否发生在波动尖峰。
**孤腿是被逆向选择出来的**(配不上恰恰因为市场在动),所以其成本分布比"平静时平仓成本"更差——**不许只在安静时段取样得出结论。**

## P1-3 · 仓位接管按既有验收标准落地

# P2 · 并行推进(不阻塞开闸,但决定这条路有没有终点)

## P2-1 · markout 测量(欠账最久的一项)

拿四次实盘约 300 笔真实成交,算成交后 **1s / 5s / 30s / 到结算** 的中价漂移,按成交方向取号。

判据:**空间 = 点差 − markout,毛空间约 0.5¢/张(单边)。**

- markout < 0.5¢ → 空间存在,后面全是工程问题;
- markout ≈ 0.5¢ → 空间被逆向选择吃平,必须靠排队位置和选择性报价抢;
- markout > 0.5¢ → **我们在补贴知情流**,现在所有调参都是在精细调节一个负数。

**这三条里哪一条都比现状好,因为现状是不知道自己在哪条上。**

## P2-2 · 未执行决策的反事实检验

07-27 07:51 那三次 `sell_rich` 一张单都没发,**因此是三个绝对干净的样本:无成交、无冲击、无自我实现。**
往后翻 tape:那三个时点之后 1s / 5s / 30s / 到结算,价格去了哪。
**这是"公允价有没有预测力"的第一份真凭据**,也直接决定 `edge_out` 门槛(现 1.09¢)该定在哪。
**与 P2-1 同一段 tape、一次跑完。**

## P2-3 · 影子成交模型校准(尺子没校过)

同一批 ~300 笔真实成交,**验证影子的成交模型命中率 ≥80%。**
未校准之前,**所有影子读数都是在量一个未知长度的东西**,包括那六台参数网格跑出来的一切。

## P2-4 · 定价核结构性盲区清单

列出定价核**在输入端就看不见**的东西,每项一行说明"它看不见什么、可能怎么亏钱、能不能接进来"。已知起点:

1. **成交的条件性**(今夜的病根;Glosten-Milgrom 1985 的出发点——点差存在正是因为每笔成交携带对方信息);
2. **排队位置**;
3. **对手是谁**;
4. **订单流失衡**;
5. **跨行权价相关性**。

**这类洞的特征是"再聪明也想不到,因为没有输入端"。列出来,它们就从盲区变成待办。**
