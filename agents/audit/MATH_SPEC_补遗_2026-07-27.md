## 甲 · 影响当前实盘决策的三条(优先补)

### 甲-1 · h\* 与亚秒尺度整个丢了 ⭐

地基 §3 的 AS(h) 曲线取 `h ∈ {5,15,30,60,120,结算}` 秒。

**但整场讨论的起点正是「5 秒不够啊,时间太长了」。** 丢掉的是最要紧的那一段:

```
h* = 实测撤单往返延迟(决策 → 交易所 ack)
```

**在 t = h\* 那一刻已经存在的不利漂移,是躲不掉的——盾、闸、任何工程手段都来不及。那是做 maker 的入场费。**
**h\* 之后才出现的漂移,大部分可以靠撤单躲掉——那不是毒性,是我们反应慢。**

**两者混进同一条曲线,就永远分不清「这门生意不行」和「我们手脚太慢」。**

**补**:h 取 `20ms / 50ms / 100ms / 250ms / 500ms / 1s / 2s` + 原有长尺度。**头条数字是 MO(h\*),h\* 必须实测,不许假设。**

**并且必须补一条测量陷阱**:10-90¢ 只有整分,**中价一跳就是 0.5¢——短尺度上 Kalshi 盘口根本没有分辨率表达 0.2¢ 的漂移。**
→ **h < 1s 只能用币安隐含概率当参照(连续、无 tick);h ≥ 1s 用 Kalshi 中价交叉验证,两者在重叠区必须一致。**

### 甲-2 · 配对/孤腿的经济学完全缺席 ⭐

**当前实盘跑的就是配对模式,而它的生死判据不在这份地基里。**

```
配对成功锁 1¢,失败留孤腿。设配对率 r,孤腿平均成本 X:
E = r·1¢ − (1−r)·X

⟹  X_max = r/(1−r) × 1¢
```

r=75% → 3¢;**r=66% → 2¢;r=50% → 1¢。**

**所以 3¢ 不是常数,是 r 的函数。** 把它写死成 3,一旦配对率掉到 60%,**每一根孤腿都在合规地放行,而整体已经是负的。**

**配套两条:**

- **孤腿是被逆向选择出来的**——配不上腿,恰恰因为市场在动。**它的成本分布严格比"平静时平仓成本"更差,不许在安静时段取样估 X;**
- **payoff 形状是空 gamma**:赢的一边被硬性封顶在 1¢,输的一边由市场走多远决定。**"锁 1¢"这个说法把一个卖波动率的头寸讲成了无风险套利。** 正确描述:**我们在用 1¢ 的价格卖 15 分钟的短期波动保险。**

### 甲-3 · post-only ⟹ 亏损没有上限(标签错误,有仓位后果)⭐

孤腿退出斜坡写着「最多认亏 3¢,亏损封顶」。**不成立。**

post-only 只挂不追,**挂单不保证成交**。行情跑过你的 3¢ 价位,单子永远填不上,**照样抱到结算。**

**3¢ 是「我最多愿意让出的价格」,不是「最大亏损」。真实亏损分布在 3¢ 之外有一条尾巴,而尾巴里装的正是跑得最快的行情。**

**后果不是措辞**:按"最坏 3¢"去倒推 clip,会系统性高估承受力。**与地基 §2.5「尾部定仓位」是同一条纪律,但那里没有覆盖这个具体错误。**

## 乙 · Greeks 的三条修正(其中一条把结论倒过来)

### 乙-1 · 二元合约的 vega 形状说反了 ⭐

**普通期权 vega 在 ATM 最大;二元合约相反。**

ATM 时 p=50%,**波动再大也还是掷硬币 → vega ≈ 0**(严格说略负)。

```
p ≈ N(d₂),  ∂p/∂σ = n(d₂)·∂d₂/∂σ
S=K:  ∂d₂/∂σ = −√τ/2                → ≈ 0
两翼:  ln(S/K)/(σ²√τ) 项主导          → 幅度最大,虚值为正、实值为负
```

**直接后果:σ 模型的精雕预算应该花在尾部价区,不是 50¢ 附近。** 这与"vega 大的地方 σ 值得精雕"这条法则本身不冲突——**冲突的是 vega 在哪里大。**

**这条直接影响六指标里的 #2(σ 比率):σ 比率应按价区加权看,权重是 |vega|,而不是均匀看。**

### 乙-2 · 条件鞅检验 ≡ σ 正确性检验(可以合并两个指标)

地基 §2.3 写对了「theta 与 gamma 在期望上精确抵消(定价 PDE)」。**但没写它的推论:**

**那个抵消只在 σ_模型 = σ_实现 时成立。** σ 估错 → theta 与 gamma 不再抵消 → **fair 出现系统性漂移。**

```
E[Δfair | 格] ≠ 0   ⟺   该格的 σ 错了(在定价核其余部分正确的前提下)
```

**所以六指标的 #1(条件鞅偏差)和 #2(σ 比率)是同一件事的两个方向,而 #1 的版本更有用**——它按 (moneyness × tte) 分格,**直接给出 σ 在哪个价区、哪个时段错了。**

**建议:#2 降级为 #1 的诊断辅助,面板仍是六个,但读法改了。**

### 乙-3 · gamma 在盾里造成单向偏差(现在就在生效,不该押后)

地基 §7 把 vega/gamma 押后到"墓地开闸前"。**gamma 这一条不能押后,因为盾现在就开着。**

盾用**当前点的 delta** 把 ΔS 换算成 Δfair。二元的 delta 在行权价处最大,gamma 在行权价两侧变号。

**⟹ 价格朝行权价方向移动时,真实 Δfair 大于线性外推 —— 盾系统性反应不足。**

**而"朝行权价跑"正是 fair 移动最快、最该撤单的方向。这不是随机噪声,是单向低估。**

**附带**:数值 delta 若用固定 $1 bump,临近结算时 p(S) 近似阶跃,**bump 跨不跨行权价会让 delta 跳档失稳。**
→ **bump 按自然尺度缩放(`≈0.1·σ√τ`)并用中心差分。** 墓地区那个 +19¢ 格子正在这个地带。

## 丙 · 两条战略层缺失

### 丙-1 · 没有"选错市场"的判据 ⭐

**整份地基都在优化"在这个市场里怎么做得更好",但没有任何一个量能得出"我们不该在这个市场"。**

```
做市盈利性 ≈ 点差 ÷ σ(持仓期间)
```

**收入被 tick 锁死在 1¢,到哪个市场都一样;风险跟标的波动走,到处不同。**

**15 分钟 BTC 很可能是全 Kalshi 这个比值最差的一档**(SVCJ:BTC 跳空在最短期限上最伤)。

**补**:用池 B 的方法对所有市场族算一遍「被动 maker 平均 markout ÷ 1¢ 点差」,**排序。** 同一套代码,边际成本近零。
**这个数如果说 15M BTC 排最后,那今晚所有调参不是错的——只是用在了错的地方。**

### 丙-2 · 双边报价的代数约束

```
edge_yes + edge_no ≡ spread   (恒等式)
```

**1¢ 点差下,两边的 edge 之和恒为 1¢。** 所以"双边同时都有厚 edge"在结构上不可能;门槛设在 θ 以上时,**双边同时挂出的条件是 spread > 2θ。**

**这条解释了为什么在 1¢ 市场里,双边报价要么门槛极低、要么只能单边——它不是工程问题,是算术。** 地基 §2.4 的 `half_spread ≥ E[AS] + 成本` 在 1¢ 上限下何时无解,由这条给出。

**相关(库存维度)**:`τ_max = (spread / (k·q·σ))²` —— **可容忍持仓时间随库存平方衰减。** 配合甲-2 的孤腿成本一起用。

## 丁 · 一条方法学补充

地基 §3 归因测试 A 有 Brier 对决和 lead-lag,**缺最干净的那个 kill-test:**

```
settle ~ a·logit(fair) + b·logit(mid)
```

**a ≈ 0 ⟹ 我们的模型没有添加任何中价里没有的信息(它只是中价的噪声版本)。**

预测包容检验问的是**增量信息**,Brier 问的是**谁分数高**——**前者才能一次性判掉整条定价核的线。** 零成本,建议放在 W2 最前。
