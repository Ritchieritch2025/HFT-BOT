# EDGE 立项:信息落地流跟随（Information-Resolution Flow）v1 · 2026-07-21

**状态**：机制证据充分,已立项。**不是**稳定盈利证据——必须按下述回测重做才能判定。

## 一句话

在**直播型、离散、逐步不可逆**的 single-name 市场（财报词汇 / 听证会词汇 / 演讲词汇）中,
一部分交易者先观察到"目标词一直没出现、剩余时间越来越少",主动买 NO;市场需要时间
完全吸收这条信息。**我们赚的是"早期观察者下单"与"全市场完成重定价"之间的延迟。**
论文 Netflix "Warner Bros" 案例是同一机制(实时观察者认识到精确词组未出现,持续买 NO,
YES 从 ~90 跌破 40);论文亦证高 VPIN 单一主体市场中单边流预测结算方向与下一桶做市亏损。

## 已验证的机制证据(2026-07-21,46 个独立市场,事件级去重后)

| 触发时会价 | 独立市场 | 赢/输 | 解读 |
|---|---|---|---|
| <80(信息落地区) | 18 | **14赢/4输(78%)** | 真 edge 所在 |
| 80-89 | 3 | 0赢/3输 | 边界,样本少 |
| **90+(机械收敛)** | 25 | **0赢/25输** | **必须隔离,全输** |

**结论**:会价<80 的信息落地流有强机制证据;会价90+是机械收敛(价格向终值收敛机械产生
高 VPIN,与真信息流表面都是"大额单边"但经济机制完全不同),必须剔除。

## 三个已犯的统计错误(回测必须修正,否则作废)

1. **样本单位**:有效单位 = `event × ticker × information episode`,**不是订单数**。
   同 ticker 的多次触发是一次信息事件的重复加仓(如 CRED 触发5次=1个独立结果)。
   合并后真实样本远小于订单数,赢率 30%(非订单级的虚高)。
2. **三种流必须分离**:
   - 信息落地流(直播内容改变剩余结算概率)→ 可能有 edge,是标的
   - 机械收敛流(事件已近终值)→ 通常不跟(会价90+全输)
   - 噪声/操纵流(大单推价但无终值信息)→ 不跟
3. **永久移动≠无风险**:目标词可能最后一分钟出现;直播/转录延迟或漏词;
   Kalshi 规则可能要求精确拼写/特定发言人;同 ticker 连续触发=高度相关集中仓位。

## 要训练的识别器（不是"预测大单后是否结算NO"）

目标：`P(information-resolution flow | X_t)`

**标签**(短期 + 终值双看):
`y_h = sign(Flow_t) · [logit(p_{t+h}) − logit(p_t)]`,分别算
30秒 / 2分钟 / 10分钟 markout + 是否持续到事件结束 + 是否与最终结算方向一致。

**关键特征**:
- 市场类型(财报/听证/演讲词汇)
- 当前 YES 价
- 事件开始后经过时间 + 预计剩余时间
- 目标词是否已出现
- 已完成的发言人/议程/问答比例
- 有符号美元成交量、VPIN、流量加速度
- 单次巨单 vs 多波阶梯扩散
- L2 同方向深度消失 + 撤单率（← 对接 deep03 的 L2 层）
- 第一波流量后的短期 markout
- 同 ticker 最近触发/持仓次数（相关性风险）

**词汇市场可直接建剩余风险率模型**:
`P(剩余时间内出现目标词 | 目前未出现) = 1 − exp(−∫_t^T λ(u)du)`
λ(u) 按公司/发言人/议程阶段/历史财报语言/剩余时间估计。
**订单流不是唯一依据,而是对事件模型的更新**:
`事件模型公允概率 + 异常订单流确认 = 交易信号`。
终极目标不是"跟随知情者",而是**让自己的直播转录+事件进度系统先于市场识别信息**。

## 回测铁律(证明它成立必须做到,否则只是机制证据)

1. **事件级重新回测**:合并同 ticker/episode 重复触发,样本单位=独立信息事件。
2. **隔离机械收敛市场**:剔除会价接近0/100(≥90 或 ≤10)的机械收敛流。
3. **时间外验证**:训练段选参数、测试段锁定后才碰(walk-forward ≥3 切点)。
4. **扣费 + 悲观成交**(taker 费 + 滑点)。
5. **相关性折算**:同 ticker 连续仓位不能当独立样本算收益/风险。
6. **markout 分层报告**:30s/2m/10m/终值,看"早期观察者→全市场重定价"延迟真实存在。
