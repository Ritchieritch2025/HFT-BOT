# 体育策略搜寻 · 测试 · 审计框架 v1（2026-07-21）

**目的**：在体育市场系统性搜寻可盈利策略。这份文档是给执行 agent 的死规矩、给审计
agent 的检查表、给决策人（ritcardo）的判定依据。三方各看对应章节。

**背景一句话**：体育量最大、散户偏差最大（买 YES 76–90%，实际结算率低得多），
但"卖会摆摊"照搬到体育已被回放证伪（扣费+悲观成交后每子类巨亏，因为比赛中信息流
比我们快）。所以要搜的是"能穿过悲观成交的 edge"，不是重复已知的坑。

---

## 0. 铁律（任何一条被违反 → 该策略结果作废，审计必须打回）

1. **时序切分，绝不随机切**。训练段=时间靠前，测试段=时间靠后。测试段在"选参数/
   选带/选子类"全部锁死之前，一个字节不许读。
2. **选择只在训练段做，规则写死在代码里**（可复现），不许手工挑、不许看测试段回调。
3. **所有 P&L 必须 扣费 + 悲观成交**。费=Kalshi 实际费率（maker/taker 分开，不是
   pre-fee）；成交=悲观打穿（taker 扫穿我们挂价才成交，成交价取最差价），或
   taker 策略含滑点。pre-fee 或"挂单全成交"的数一律不接受。
4. **walk-forward ≥3 个切点**。单一切点为正不算数，要看优势在多个切点上稳不稳。
5. **机制检验**：赚钱的参数/带是连续一片（对得上经济解释=真机制）还是锯齿
   （=噪声）。说不清机制的正收益，按噪声处理。
6. **诚实上报**：测试段为负/平就如实报，绝不回头拿测试段调参数"救"。
7. **样本量门槛**：任何结论至少覆盖 ≥30 个不同赛事/事件 且 ≥200 个已结算单，
   否则标注"样本不足，不下结论"。

## 2. 要搜的三个方向（按优先级，每个都必须过铁律）

### 方向 A：赛前 vs 赛中切开（最可能藏干净 edge）
- **假设**：比赛**开始前**市场没有实时信息流，散户乐观税可能安全收；比赛**中**是雷区。
- **切法**：用 `market_close` 和成交时间戳，把每个市场的成交分成"距结算 >T 小时"
  （赛前代理）和"临近结算"两段，分别跑"卖会摆摊"回放。
- **判定**：赛前段扣费悲观后为正、样本外三切点稳、且能解释机制（赛前无信息优势者）→
  候选；赛中段预期为负（确认雷区）。

### 方向 B：跟大单的体育版（已在单名 60-79 段验证最强）
- **假设**：比赛中大额单边流=有人看到现场变化（进球/伤退），跟着下注赚慢人的钱。
- **做法**：把 `strategies_lib.Rc2Replay` 的 `universe_sql` 改成体育，按子类×价位段
  跑，找哪个组合样本外为正。注意：之前"体育跟单无效"是没分子类/价位段测的，重测。
- **判定**：某子类×价位段样本外三切点稳定为正 + 样本量够 → 候选。

### 方向 C：fade 赛前极端长price（统计套利味）
- **假设**：高尔夫"某人夺冠"87% 买 YES / 4.5% 实现，**赛前**买便宜"不会"可能是干净
  的概率套利（赛前谁夺冠无人知）。
- **做法**：限定赛前 + 卖价 <15¢ 的"会"（=买 >85¢ 的"不会"），回放扣费悲观。
- **风险**：长price 单笔亏损巨大（幅度赤字），必须看最差单笔 + 破产概率，不只看均值。
- **判定**：样本外为正 且 最坏回撤可承受 → 候选。

1. **一个回放脚本**（改自模板，参数写死），审计能一键复现。

4. **一句话判定**：`候选 / 否决 / 样本不足`，附最关键的那个数字。

## 4. 审计 agent 的检查表（逐条打勾，任何一条 ✗ → 打回重做）

- [ ] 切分是时序不是随机？（看代码里切点是 ts 还是 random）
- [ ] 测试段是否在选参数后才被读取？（看代码结构：train 选带→锁死→才 stream test）
- [ ] P&L 是否扣费？费率数值是否写明、是否≈Kalshi 真实？
- [ ] 成交是否悲观？（有没有"挂单全成交"的偷懒；taker 有没有滑点）
- [ ] walk-forward 是否 ≥3 切点？优势是否跨切点稳定（不是只有一个切点为正）？
- [ ] 样本量是否过门槛（≥30 赛事 & ≥200 单）？
- [ ] 机制是否连续可解释（不是锯齿噪声）？
- [ ] 有没有"测试段回调救参数"的痕迹？（对比训练选出的参数和最终用的参数是否一致）
- [ ] 最坏单笔 / 回撤是否报告（尤其方向 C 长price）？
- [ ] 结论措辞是否诚实（负/平有没有粉饰成正）？

审计输出：每个方向一行 `通过 / 打回(原因)`，附最可疑的一个点。

## 5. 决策人（ritcardo）的判定依据

看审计通过的候选，对每个问三件事：
1. **样本外三切点都为正吗？** 有一个为负就是薄/脆，不是稳。
2. **机制我能用一句人话解释吗？** 解释不了的正收益别信。
3. **最坏单笔我扛得住吗？** 尤其长price 策略，均值好看单笔能爆仓。

判定分三档：`真钱小额试点 / 继续影子攒数据 / 否决`。
**没有任何策略因为"回放好看"就直接上真钱——必须先在实盘影子跑未来数据 ≥1–2 周。**

## 6. 已知结论（省得执行 agent 重走死路）

- 体育"卖会摆摊"（全程、不分赛前赛中）：**已证伪**，扣费悲观每子类巨亏。别重测。
- 体育转播提词（WNBA/MLB 解说提词）：**坑**，解说话痨什么都说。别碰。
- 单名（非体育）优选带 20-29+50-69：样本外过了"是真 edge"关，但薄（扣费后盈亏线
  挣扎），未过"稳赚"关。这是对照基准。
- 提词类里稳的是：财报会、电视/听证（话题窄）；坑是：政客演讲、体育转播（话痨）。
