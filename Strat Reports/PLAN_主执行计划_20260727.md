## 治理规则(先于一切)

2. 规格逐条对账,分五态: 已实现有测试证据 / 已实现缺实盘证据 / 影子验证中 / 仅计划 / 与现有代码冲突。已落地零件(σ传导、毒性表、盾A阶段、孤腿退出)不许重新实现。
3. 分类写入 SPEC_AUDIT_LEDGER.md,之后所有批准在此账本改状态。
4. 一切来自研究/论文/市场平均的数字(2σ、3¢、75%、0.27¢等)入代码必须是可配置参数加来源注释,禁止裸数字。

6. 实盘操作(开闸/重启/调参)单独请求确认,默认禁止。
7. 禁止 reset、checkout、覆盖式操作。
8. 报告必须区分市场平均基准与我们自己的实盘EV。
9. 原始事件和上下文尽量多存(成交快照、被拦单反事实、锚tick);面板指标只有六个,不加第七个。

## 组件化原则(所有决策函数的构造标准)

每个决策部件(盾、闸、毒性、σ、GLFT、配对、退出)必须满足:

1. 纯函数: f(市场快照, 持仓状态, params) → 决策。不读全局、不读钟表、不藏状态;需要的状态显式传入。
2. 参数全部外置: params 来自配置,含来源注释;代码里无裸数字。
3. 确定性: 同输入同参数 → 同输出,逐字节。回放必须能精确复现历史决策。
4. 决策快照记录组件版本号和参数哈希: 任何一笔历史成交都能回答"当时是哪个版本的哪套参数做的决定"。
5. 测试分两档,别陷证明陷阱:
   - 动真钱的改动(风控、费用、下单路径、clip): 单元黄金用例 + 回放一致,必须过
   - 其他一切(信号、加价、阈值): 影子里直接试,计数器被动记边际贡献(¢),不设前置证明
   - 砍零件只在每周回顾做,标准是"明显亏钱或明显碍事",不要求每个零件自证存在
6. 部件间只通过定义好的接口传值(如毒性输出加价¢,GLFT输出offset¢),禁止跨部件读内部状态; redundancy扣减在接口层做,防同一风险重复计费。
7. 迭代速度优先: 影子层随便改随便试,不需要批准; 批准流程只覆盖实盘行为的变更。

对应关系: params=权重, 回放=训练集, 影子=验证集, 小信封实盘=测试集, 消融=特征重要性, 晋升/降级=部署/回滚。

## 公式表(实现以此为准,dir: 多YES=+1,多NO=-1,价格单位¢,概率p∈(0,1))

定价与鞅
```
fair(t) = E[settle | F_t] × 100          # settle ∈ {0,1}
鞅检验:   E[Δfair] = 0 (无条件)  且  E[Δfair | moneyness×tte 格] = 0 (条件)
σ_contract = |dP/dS| · σ_index · √τ      # 合约在τ秒内的正常晃动(¢)
```

四段账(逐笔恒等式,兼代码断言)
```
fair_f ≜ fair(t_成交, 冻结参数)          # 定义一次,两处共用
edge_quote = dir·(fair_q − price)
staleness  = dir·(fair_f − fair_q)
AS         = −dir·(settle − fair_f)
断言: dir·(settle − price) ≡ edge_quote + staleness − AS    # fee两边同减,不入恒等式;实付(取整)单独记
诊断(不进恒等式): model_update = fair(t_成交,实时参数) − fair_f
```

逆向选择
```
E[Δfair | 被成交] = Cov(Δfair, 1{成交}) / P(成交)        # E[Δfair]=0 时严格成立
MO(h) = dir·(参照(t_f+h) − 参照(t_f))     # 两端同一把尺子,h→0 时 MO→0; h ∈ {20,50,100,250,500ms,1,2,5,15,30,60,120s,结算}
       # h < 1s 参照=币安隐含概率; h ≥ 1s 参照=Kalshi中价; h* = 实测撤单RTT,MO(h*)为头条
对照组回归: Δfair = α + β·1{成交} + γ·状态 + δ·(1{成交}×状态) + ε   # 状态主效应γ必须在,否则交互项吸收"该状态fair本就在动"; α≈0; 按市场窗聚类
```

漂移与检测
```
Δfair ≈ delta·ΔS + theta·Δt + 残差       # 检测只用 delta·ΔS 项; theta与gamma期望抵消(仅当σ对)
z = ΔS / (σ_index · √Δt)                 # 一切漂移阈值定义在z上,不用绝对¢
delta = [p(S+b) − p(S−b)] / (2b),  b = 0.1·σ_index·√τ   # 中心差分,自然尺度bump
```

Greeks(二元)
```
p = N(d2),  d2 = ln(S/K)/(σ√τ) − σ√τ/2
vega = n(d2)·∂d2/∂σ;  ATM≈0,|vega|峰值在|d2|=1 (p≈16¢/84¢);高vega区 ≈ 5-35¢ 与 65-95¢ (10¢处仍有峰值93%)
```

log-odds
```
L = ln(p/(1−p));  ΔL ≈ Δp/(p(1−p));  YES/NO镜像 = 取负
taker费 7·p(1−p)¢ ≡ 0.07 L单位(公式层; clip=1时取整主导,用实付)
跨行权价基础价差按恒定ΔL设,再换算回¢
```

配对经济学与双边约束
```
E = r·1¢ − (1−r)·X   ⟹   X_max = r/(1−r)·1¢        # r=配对率,实时计算,3¢仅是r=75%的先验
edge_yes + edge_no ≡ spread;  双边同挂条件: spread > 2θ
τ_max ∝ (spread/(q·σ))²                              # 可容忍持仓时间,q=库存
clip ≤ 预算 / (k·单笔最坏)                            # k=预设可承受连亏次数,按尾部不按均值
```

估计与收缩
```
EB收缩: est = w·x̄ + (1−w)·μ_prior,  w = n/(n + σ²_格内/τ²_先验)   # 先验只定符号/排序
毒性EWMA: α = 1 − 0.5^(1/halflife_fills)
聚类bootstrap: 重抽单位=市场窗口; 有效n≈窗口数,不是笔数
```

归因检验
```
A0 包容: settle ~ a·logit(fair) + b·logit(mid);  a≈0 ⟹ fair无增量信息,定价核判死
A  lead-lag: Δmid(t→t+h) = β·(fair−mid)(t);  β>0=领先市场
   Brier: mean[(fair/100 − settle)²] vs mean[(mid/100 − settle)²],分tte层
B  速度: 陈旧项 vs tape平均maker同口径; 反事实=撤单延迟+X ms重放的PnL差
C  选择: 我们的MO(60s) − tape平均maker的MO(60s),同格量权汇总
D  税:  净PnL按先验税格/中性格分解
```

定价(GLFT,影子先行)
```
λ(δ) = A·e^(−kδ)                          # 从挂单历史拟合(delta_c,exposure_s,fills)
d0 = sqrt(σ²γ/(2kA)) 系列闭式解见 glft_quotes.py (变量delta改名offset_c)
half_spread(状态) = GLFT基础项 + E[AS|状态]  ;  闸门只留 |z|>3 尾部
```
