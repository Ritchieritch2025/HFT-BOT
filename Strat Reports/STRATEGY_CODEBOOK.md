## S-A · 摆摊(maker):BO-1 论文版 / RC-4 带图版
═══════════════════════════════════════

**大白话**:在提词类市场常驻卖"会",收上头买家多付的钱,持到开奖。

**精确规则(两版只差价位带)**:
```
宇宙   : 单名市场(Mentions/Companies 类)∪ 动态发现的新市场
         剔除 短语风险=high(缩写/数字类,Netflix 定式)
挂价   : 每笔成交后,影子卖价 ask = 最新成交价 + 2¢(四舍五入到 0.01)
带     : BO-1 → ask ∈ [30,70](论文原带)
         RC-4 → ask ∈ [20,39] ∪ [60,69](FM-1 双引擎带,跳 40-59 死亡谷)
成交   : 有 taker 买"会"且打印价 > ask + ε(严格打穿,悲观口径)
         成交量 = min(打印手数, 200 − 该市场已持仓)     ← 唯一的帽
撤退   : trailing VPIN ≥ 0.9 → 停止该市场报价;< 0.8 恢复
         VPIN = 最近20个$500美元桶的 |净签名流|/总流 均值,仅内部价 30-70 计
持有   : 到结算。P&L/手 = 卖价 − (100 if 开"会" else 0)
```

**参数表**

| 参数 | 值 | 出处 |
|---|---|---|
| 报价偏移 | +2¢ | 悲观成交约定 |
| 单市场帽 | 200 手 | 防单市场独大 |
| VPIN 桶/窗/阈 | $500 / 20桶 / 0.9撤 0.8回 | 论文 Table 8(悬崖 0.86~0.94) |
| BO-1 带 | 30–70 | 论文 §5-6 |
| RC-4 带 | 20–39 + 60–69 | FM-1(RESULTS_V2 §G, CONCLUSIONS H8) |

**代码**:`watchtower/shadow/bo1.py`(ShadowMaker 类,~90 行;
`on_trade`=成交判定,`_hydrate`=重启恢复持仓,`update_quote`=挪价)
VPIN 状态机:`watchtower/detectors/core.py::VpinDetector`
**账本**:`bo_shadow_fills.ndjson` / `rc4_shadow_fills.ndjson` →
日更结算成 `*_ledger.csv`(strict 列=严格打穿口径,以它为准)

## S-B · 跟单(taker):RC-2 跟随知情"不会"流
═══════════════════════════════════════

**大白话**:有人疯狂单边扫"不会" = 他知道点什么,跟着买,赚还没反应过来的人的钱。

**精确规则**:
```
触发   : 单名市场,滚动10分钟内
         净签名手数 F = Σ(±手数) ≤ −300(净"不会"方向)
         且 |F| / 总手数 ≥ 0.8
入场   : 立刻以市价买"不会" 100 手,成本 = (100 − 现YES价) + 1¢滑点
         手续费 = 7·p·(1−p)¢(taker 费,结算时扣)
分带   : 按触发时 YES 价记 band ∈ {0-19, 20-39, 40-59, 60-79, 80+}
         主力带 = 60-79(回测 +11.4¢/手);其余带为探边仓(画边界用)
冷却   : 同市场 30 分钟
持有   : 到结算。P&L/手 = (100−成本 if 开"不会" else −成本) − 费
```

**参数表**

| 参数 | 值 | 出处 |
|---|---|---|
| 300手 / 0.8 / 10min | 触发三件套 | H7 回测原型 |
| 100 手/次 | 固定仓 | 试点规格 |
| 滑点 +1¢ | 入场成本 | H7 v2 口径 |
| 主力带 60–79 | 唯一验证为正的带 | H7 v2(+11.4¢, 11/12天正) |

**代码**:`watchtower/shadow/rc2.py`(Rc2Shadow 类,~70 行;`on_trade`=触发+入场)
**账本**:`rc2_shadow_fills.ndjson` → `rc2_shadow_ledger.csv`(taker 口径含费)

## S-C · 百元快转:T100(资金受限版摆摊)
═══════════════════════════════════════

**大白话**:只有 $100 时怎么玩——只做当天开奖的,钱当天回笼再战。

**精确规则**:S-A 的 RC-4 带 + 三条资金约束:
```
只进 24 小时内开奖的市场;单市场押金 ≤ $25;总押金 ≤ $100
押金/手 = (100 − 卖价)/100 美元;开奖即解锁回现金池
```
**代码**:`watchtower/shadow/t100.py`(T100 类,~150 行;含 `_hydrate` 现金重放、
`poll_settlements` 开奖回款)。**账本**:`t100_fills.ndjson`(settle 行含现金流水)

## 共用底座
═══════════════════════════════════════

- 数据:公开成交流 3s 轮询(`watchtower/feed.py`),零鉴权零费用
- 市场状态:每市场滚动 10min/60min 窗(`watchtower/state.py`)
- 探测器:WHALE/BURST/SURGE/VPIN(`watchtower/detectors/core.py`,阈值全在 `config.py` 带出处)
- 动态进市场:`watchtower/discovery.py`(新市场首笔成交后几秒入宇宙)
- 安全重启:`watchtower/restart.sh`(杀→验0→启→验1)
- 日更结算:`bo_daily_update.py`(maker 口径 + taker 口径两套结算函数)
