## 0. 公理层(一切的地基)

- **A1 价格 = 条件期望**:fair(t) ≡ E[结算 | t 时刻信息]。引擎的 fair 是它的近似。
- **A2 鞅性**:A1 成立 ⟹ E[Δfair] = 0(无条件)。测出显著无条件漂移 = 定价 bug,不是机会。
- **A3 钱在条件里**:E[Δfair]=0 但 E[Δfair | 被成交] ≠ 0。全部业务 = 估计并定价各种条件期望。
- **A4 没有预测租**(Della Vedova + 自家尾部/σ研究):excess accuracy ≈ 0。利润三来源:执行租(速度/队列)、行为税(对手系统性错价)、防守(躲知情流)。任何新策略先答:赚的是哪种租?答"预测租"直接毙。

## 1. 坐标系分工(每个量只在自己的空间里合法)

| 空间 | 用途 | 禁止 |
|---|---|---|
| 分(¢) | 记账、PnL、风控、熔断、预算 | 跨价位比较信号 |
| log-odds L=ln(p/(1−p)) | 信号、毒性函数自变量、跨价位汇总、价差设定(恒定ΔL=恒定信息收费)、校准回归 | **鞅检验(Jensen假漂移)** |
| 指数 z = ΔS/(σ_S√Δt) | 漂移/刀检测,regime 无关 | — |
| 概率空间 | 鞅检验唯一合法空间 | — |

事实:taker费 7·p(1−p)¢ ≡ 0.07 log-odds 单位(常数)。**边界条款:此恒等式对公布的连续公式严格成立,但 Kalshi 逐单向上取整——clip=1 时取整主导(50¢处+14%,10¢处+59%),两翼有效费用显著高于 0.07 单位;小 clip 的费用一律用取整后实付计,不用公式。maker 费 0.0175·p(1−p) 仅 ~80 个系列收取,清单入 taxonomy 并版本化。** YES/NO 镜像在 L 空间 = 取负。

## 2. 核心方程(五条)

1. **四段账恒等式(逐笔精确,兼代码审计)**
   `结算账 = 挂单edge + 陈旧项 − AS − 费`
   - 挂单edge = dir×(fair(挂单时) − 价) → 报价位置的成绩
   - 陈旧项 = dir×(fair(成交时,冻结参数) − fair(挂单时)) → 撤单延迟的成绩
   - AS = −dir×(结算参照 − fair(成交时)) → 状态定价的成绩
   - 模糊带声明:fair 自身滞后会使陈旧项漏入 AS,分界精度受模型延迟限制。
2. **逆向选择 = 协方差**:E[Δ|成交] = Cov(Δ, 1{成交}) / P(成交)。分子靠躲毒时刻降,分母靠良性状态多成交升;"少挂/多挂"是同一分式两端。护栏:AS 均值旁必须并排 Σ美元损失(防 Goodhart)。
3. **漂移分解**:Δfair = delta·ΔS(信息项,检测只看它) + theta·Δt + 残差(模型自更新)。theta 与 gamma 在期望上精确抵消(定价 PDE),不单算。**推论:该抵消仅当 σ_模型=σ_实现时成立 ⟹ E[Δfair|格]≠0 ⟺ 该格 σ 错(定价核其余正确前提下)——条件鞅检验就是分格 σ 检验。** delta 用数值差分,bump 按自然尺度 ≈0.1·σ√τ + 中心差分(固定 $1 bump 在临近结算的阶跃区会跳档)。
4. **定价优于闸门**:half_spread(状态) ≥ E[AS|状态] + 成本;闸门 = 成交率归零的退化解,只留 >3σ 尾部。GLFT 给最优解结构(σ、库存、λ(δ)拟合)。跨行权价基础价差按恒定 ΔL 设。
5. **尾部定仓位**:期望定该不该做,尾部定做多大。clip 按"预算扛住连续 k 次最坏"倒推(墓地贵侧 +19¢ 均值与 −95¢ 单次共存)。**post-only 退出单不保证成交 ⟹ "最多让 3¢"是意愿价不是最大亏损,尾巴延伸到结算——clip 倒推必须用真实尾部分布,不用退出斜坡标签。**
6. **配对经济学(当前实盘生死判据)**:E = r·1¢ − (1−r)·X ⟹ X_max = r/(1−r)·1¢(r=75%→3¢,66%→2¢,50%→1¢)。**孤腿成本上限是配对率的函数,不是常数,引擎按实时 r 计算。** 两条附则:孤腿是被逆向选择出来的(配不上正因为市场在动),X 不许用安静时段样本估;payoff 是空 gamma(赢封顶 1¢、亏随行情),正确名称是"卖 15 分钟波动保险",不是"无风险锁差"。
7. **双边代数约束**:edge_yes + edge_no ≡ spread。1¢ 点差下双边同厚不可能;双边同挂条件 = spread > 2θ。half_spread ≥ E[AS]+成本在 1¢ 上限下何时无解,由此判定。库存维度:τ_max ∝ (spread/(q·σ))²,可容忍持仓时间随库存平方衰减。

## 3. 估计器(全部走 replication 工具包,引擎与实验同尺)

- **对照组回归(样本量×100 的杠杆)**:所有报价时刻上 `Δfair = α + β·1{成交}×状态 + ε`。α≈0 内嵌鞅检验/安慰剂;β = 毒性函数。误差按市场窗聚类。
- **条件鞅检验**:按 (moneyness×tte) 分格 E[Δfair|格]≈0;无条件零可由相消的条件漂移伪装,必须跑条件版。非零格 = 定价 bug 清单。
- **AS(h|状态) 曲线**:h∈{20ms,50ms,100ms,250ms,500ms,1s,2s,5,15,30,60,120s,结算}。**头条数字 = MO(h\*),h\* = 实测撤单往返延迟(决策→ack),必须实测不许假设。h\* 之前已存在的漂移是 maker 入场费(任何工程都躲不掉);h\* 之后的漂移是我们手脚慢(可修)。两者混在一条曲线里,永远分不清"生意不行"和"反应太慢"。** 测量分辨率规则:Kalshi 中价一跳 0.5¢,h<1s 用币安隐含概率当参照(连续无 tick);h≥1s 用 Kalshi 中价交叉验证,重叠区必须一致。渐近值=永久冲击(信息),隆起=暂时冲击(流动性)= Glosten-Harris 实测版。远端必含结算(不受自家 fair 污染)。
- **有效样本量**:聚类单位 = 市场窗口,不是笔(刀口成交串相关;9347笔可能只有√200的功效)。所有 CI 用窗级 bootstrap。
- **经验贝叶斯收缩**:估计 = w·格均值 + (1−w)·先验,w = n/(n + σ²/τ²)。取代一切手拍权重。大盘先验只定符号/排序,幅度由自家样本定。
- **连续化**:毒性函数自变量 = (log-odds 或 moneyness d) × tte 连续 + taker方向离散;允许在 50¢ 与墓地边界断裂(实测符号翻转处)。
- **归因测试(edge 从哪来)**:
  A0 **包容检验(kill-test,W2 最前,零成本)**:`settle ~ a·logit(fair) + b·logit(mid)`。a≈0 ⟹ fair 未添加任何中价之外的信息(只是中价的噪声版),整条定价核判死。Brier 问谁分高,包容检验问增量信息——后者才能一次判线。
  A 定价:Brier(fair) vs Brier(mid) 分tte层 + lead-lag `Δmid ~ β(fair−mid)`,β>0=领先市场;
  B 速度:陈旧项 vs tape平均maker同口径 + 延迟+X ms 反事实回放(速度的美元汇率);
  C 选择:同格 matched markout(我们 vs tape平均maker);
  D 行为税:PnL 按税格/中性格分解。
  预判:A 平、B C 正 ⟹ 资源全押执行链。
- **基准纪律**:合法基准 = 自家fair(决策)/ 结算(真理)/ 前一笔成交价(外部参照)。**VWAP 永不入基准**(Della Vedova 污染定理:自评基准制造 −0.178 假权衡)。

## 6. 反例清单(每条都有尸体)

1. log-odds 空间跑鞅检验 → Jensen 假漂移。
2. VWAP 当基准 → 自评污染(Della Vedova)。
3. 按笔数算 n → CI 虚窄 7 倍(RC-2)。
4. 阈值用绝对¢不归一 → 高波动时全挡单(0.3¢事故);一切阈值在 z 或 σ 单位。
5. AS 比率单独当 KPI → 靠不成交刷分。
6. regime/状态判定层用未来数据 → FST 两侧核事故;判定层单独做 look-ahead 审计。
7. 先验幅度直接当参数 → 平均maker的遭遇≠我们的遭遇;先验只定排序。
8. 均值定仓位 → +19¢均值格一次 −95¢;尾部定 clip。
9. 小样本二维条件化 → 225笔撑不起两维(ER实验教训);维度数跟着样本量走。
10. post-only 退出价当"最大亏损" → 挂单不保证成交,尾巴到结算;clip 按真实尾部倒推。
11. 普通期权 Greeks 直觉套二元合约 → 二元 vega 在 ATM ≈0(掷硬币不怕波动),峰值在两翼;binary 的每个 Greek 都要单独推导,不许搬 vanilla 结论。
12. 孤腿成本用安静时段样本估 → 孤腿是被逆向选择出来的(配不上正因为市场在动),必须用孤腿事件自身的分布。
13. 当天发现的规律当天接线 → 样本内信号一律等样本外复验(VPIN 反向信号、墓地金矿格均按此执行)。
14. 市场平均 maker edge 当自家策略 EV → WHO_PROFITS 的 +0.27¢ 是"平均在场者的地板"(不含我们的队列位置/撤单延迟/被针对性挑选),只作市场选择先验与对照基线;报价宽度、size、止损、实盘 EV 一律由自家成交数据定。
15. 分层口径不版本化 → 市场族分类规则版本号 + catalog 快照哈希 + 逐 ticker 归属 + 未识别清单四件套随每份报告存档,否则口径一变历史结果全部不可复现。

## 8. 施工顺序(按补遗修订)

- **立刻**:post-only 标签修正 + clip 按真实尾部重倒推(§2.5)→ 孤腿 X_max 改为 r 的函数(§2.6)。
- **W1(照明)**:ledger+陈旧项 → 条件鞅检验+对照组回归 → 连打刹车 → **盾的 gamma 修正**(当前 delta 线性外推在"朝行权价跑"方向系统性反应不足,盾已在生效,不许押后)+ bump 自然尺度化。
- **W2(裁决)**:**A0 包容检验最前(零成本 kill-test)** → 六指标自动化 → lead-lag → EB收缩接毒性表 → **市场族 spread/σ 排位(§7)**。

- **押后**:延迟反事实模拟、vega 精算(墓地开闸前)、活力监控(印钱后)、λ/GH(扩体育/单名前)。
