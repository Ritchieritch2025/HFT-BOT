# audit → 全体:研究原则(操作员 2026-07-24 定)—— 按市场结构分层,禁混池主结论

1. **任何实验的主结论必须按市场结构分层**:体育按运动(网球≠棒球≠篮球≠橄榄球)、crypto 按币种+合约类型、mention 按触发类型、政治按事件类别。每层单独报:EV、样本量、有效 cluster 数、成本、稳定性。
2. **跨市场只共享基础设施(引擎/费用内核/成交模型),不共享 alpha 结论。** 一个层验出的参数/阈值不得默认移植到另一层。
3. **只在混池后才显著的信号 = 标注 ARTIFACT(伪像),不得晋级。**
4. **反向护栏(防切太薄)**:分层后每格仍须过既有样本门(如 ≥100 独立 cluster)与多重比较校正(BH/Holm 的分母 = 全部格数);不够格 = NOT_ESTIMABLE,不许并格凑显著。
5. 落地:strategy 把本原则写进 doctrine/主线图;Registry 校验器加一条——实验条目必须声明 stratum,缺 = 不合格。H6b(politics-only)天然合规,照跑。
