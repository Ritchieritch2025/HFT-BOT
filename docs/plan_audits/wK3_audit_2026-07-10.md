## FINDINGS (most severe first)

**N1 — double-refund via a copied handle breaks conservation → negative `used_` → every cap defeated.** `Reservation` is a plain copyable struct; the `closed` guard lives in the struct instance, not in the ledger keyed by slot, and the ledger keeps NO record of which slots are open. A strategy that copies the handle and closes both copies double-releases the same amount. Probe P3: reserve $1 → `used_total=1000000`; `Reservation b = a; refund(a); refund(b);` → **`used_total = -1000000`**. Contradicts RESULT's "settle/refund idempotent-guarded". Fix: move-only, or track live slots in the ledger keyed by slot. risk_ledger.hpp:92-103, 162, 175.

**N2 — no validation of `req.exposure < 0`; negative exposure corrupts a layer (fail-OPEN, violates S2).** `reserve()` takes exposure with no clamp/reject. Probe P2: exposure `-5000000` → admitted, `used_total=-5000000` → phantom headroom. risk_ledger.hpp:138.

**N3 — signed int64 overflow in `used_ + e` wraps NEGATIVE past the cap → admits an unbounded breach (also UB).** Probe P1b: total cap $1; reserve `INT64_MAX-100` → `used+e` overflows negative, passes headroom → admitted. Low practical reachability but exactly the wrap-to-room bug. risk_ledger.hpp:140-151.

**N4 — `__unknown_factor__` is NOT the "most conservative bucket"; it inherits the global per-factor default kNoCap (infinite) → unclassifiable orders get INFINITE factor headroom (fail-OPEN).** Probe G: default `Caps{}` → 1000 unclassifiable orders all admitted. Contradicts RESULT's "most conservative bucket". Fix: construction-time tight default independent of per_factor. risk_ledger.hpp:22-24, 61, 131, 144.

**N5 — `client_order_id` is ts-dependent, not slot-pure → a retry with a different `ts_ns` yields a DIFFERENT id, breaking contract #9.** Probe H: same slot, ts=1000 vs 2000 → different ids. Fix: capture ts_ns in the Reservation at reserve. risk_ledger.hpp:40-43, 183-190.

**N6 — factor-key DERIVATION rule is not implemented; `factor` is caller-supplied.** The W says derivation "is part of the W". The header only maps empty→unknown; no series/strike mapping code. Defensible as deferred-to-caller-with-documented-convention but a partial scope miss. risk_ledger.hpp:19-24, 84-90.
