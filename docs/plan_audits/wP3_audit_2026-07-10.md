### Findings
**N1 — criterion (6) "trade volume does NOT trip" is a vacuous demonstration.** test:92 asserts `jump_breaker(lb,lb,300,book_updates=0) is False` — passes NO trade-volume argument (there is none) and merely negates the two trip conditions. Mutation M6a — `book_rate = (book_updates + trade_volume)/window` with `trade_volume=0` default — PASSES all 8 tests. The shipped code is correct (volume is not an input) but the guarantee rests on the parameter's ABSENCE, untested. The most safety-critical acceptance point (BADAMS defense) has its negative half untested.

**N2 — no cap_max validation → a Q8 deadlock on out-of-contract input.** `quote(MID, inv=+5, ..., cap_max=-25)` → reason=flat_capped, bid=None, ask=None — a LONG with the EXIT side suppressed, exactly the rodlaf deadlock. Root: cap = cap_max·t_frac = -12.5, so both `inv>=cap` and `inv<=-cap` fire. cap_max=0 / horizon_s=0 suppress both at inv=0. Garbage config, but unguarded — inconsistent with fair.py's S2 fail-closed. One-line guard closes it.

**N3 — criterion (2) holds in δ_lo but NOT in emitted cents near the band edge.** At fair=2c, inv 0→100: δ_lo 0.225→0.825 (monotone) but emitted cent spread 200→…→100 (narrows at inv=100). Cause: skew crushes the quote against the 1c floor — economically-correct dump-near-floor, so defensible, but the literal wording is violated in cents and no test covers cents-space.

**N4 — breaker wiring is fail-OPEN by default.** jump_breaker is standalone; quote() defaults breaker_tripped=False. NaN lo-mid → False (keep quoting); dt<=0/window<=0 → False. Acceptable for a pure-math layer (integration deferred), but every default on bad/missing data chooses keep-quoting, against fair.py's S2 doctrine.
