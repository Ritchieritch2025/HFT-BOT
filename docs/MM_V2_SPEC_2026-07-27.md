## §2 刺1修复:门槛刻度归一化(废除"¢直尺")

**病**:绝对¢门槛跨价区不可比(2.5¢=5¢合约的50% vs 50¢合约的5%)。

**修**:门槛的**计量单位**改为"本合约短窗波动的倍数":

```
σ_contract(τ_ref) = dP/dS × σ_S × √τ_ref        (¢,本合约τ_ref秒内的一σ价格波动)
所需edge(¢) = m* × σ_contract + 毒性addon(¢) + ...
```

- m*(无量纲)是全价区统一的旋钮;换算成¢在最后一步(执行层仍是美分,
  账本不动——log-odds纪律保留:统计归一,钱用美分);
- τ_ref初值=30s,户口本登记,由"归一化后各价区markout分布是否坍缩为同一条"
  检验校准——**验收标准:归一化单位下,毒性表各价区桶的基线markout应近似同分布**;
  仍显著分层=归一化因子选错,换刻度重来(候选:log-odds刻度)。

## §3 刺2修复:毒性标签去污(慢fair污染)

**病**:markout用CF慢fair计量,"对手毒"和"我们慢"混账;锚上线后历史毒性
数字全部带偏。

**修**:标签流水线版本化:
- markout_v1(慢fair口径,现存)冻结存档,只读;
- **markout_v2 = 锚修正fair口径**:fair_anchored(t+Δ) − 成交价。锚流有录
  (今日起Coinbase/Binance实时;07-12..23有Binance历史档),**历史成交全部
  可回算v2标签**;
- TOX表切v2标签重训;v1/v2差值单独成表=**"我们自己慢"的成本计量**
  (它应随锚上线趋零——这本身是锚的验收指标之一);
- 所有下游(margin、验收线)引用标签版本号,禁止混用。

## §4 刺3修复:趋势双重计费

**病**:σ估计故意不去均值(趋势留在σ里,因模型假设零漂移);锚显式修正
趋势后,同一份趋势被计费两次→门槛虚高、白弃成交。

**修**:σ口径与锚信任态联动(一个开关,不是新参数):

```
ANCHOR_OK      → σ用去均值版(趋势已由锚显式处理)
ANCHOR_DISTRUST/DOWN → σ回不去均值版(趋势重新算进风险,保守回退)
```

同时修错配3(尺子口径):**衡量perp移动用perp口径σ,衡量CF/合约风险用
BRTI口径σ**,两把尺各自滚动维护,禁止交叉使用。

## §5 刺4修复:size层立公式(g不再是空壳)

```
size = clip_max × clamp(edge富余* / m_full, 0, 1) × Q(流量质量) ,向下取整,最小1
```

- edge富余* = (实际edge − 所需edge)/σ_contract(归一单位,承接§2);
- m_full:富余达到多少个σ给满仓——**由Kelly校准器估计**:
  f* ∝ 实测edge均值/实测每张结局方差(桶内滚动),m_full=使size曲线
  逼近0.25×Kelly(quarter-Kelly,保守系数属治理常数);
- Q(流量质量)=1−VPIN百分位映射(散户时段Q→1,毒时段Q→0);
- clip_max仍属治理层硬帽;金丝雀期clip_max=1(g先以影子记账形式空转
  积累校准数据,不控真单——**公式先上岗记账,后接权力**)。

## §5b 成交后管理:每事件重估的持仓决策函数(操作员规格 2026-07-27T04:00)

**病灶(L1实盘首笔证实)**:`MM_PAIR=0` 下成交即闩锁、唯一出口是15分钟后
结算。首笔 买NO@79¢(模型83¢,edge 3.97¢,零费)→ 中途NO曾涨至~87¢(未兑现)
→ 末段BTC反超$50 → 结算归零 −$0.79。缺的不是"一条出货单",而是**成交后的
动态fair追踪 + 库存风险判断 + maker退出 + 有界亏损退出**。

**每个行情事件(不是定时)对每个持仓重估五问:**
1. 当前fair相对成本是变好还是变坏(Δ = fair_now − cost,带方向);
2. 当前盘口能否以**maker**价格退出(对面bid是否够到目标,深度是否够);
3. 继续持有到结算的期望值(用当前fair + 剩余时间的方差,不是入场时的);
4. 剩余时间 / σ / 库存占用 / 退出成交概率(队列位置+流速估);
5. **fair已穿过成本时:是否减仓**,而非继续等待回到盈利。

**输出四种路径(连续判据,无模式开关):**
- 先有利后反转 → maker出货锁定,目标价 = cost + max(min_profit, k·σ_contract)
  (σ标度:高波动时目标利润自动放大,不写死分数);
- 成交后立即反向 → 不等盈利:先撤该市场其余入场单,必要时**有界亏损**maker退出;
- 走势慢 → 仓位小且等待成本低可持有;否则降库存;
- 高波动 → 机会多但逆选择与风险同步放大,**不得简单认为波动高就多挂**
  (量的上调必须由实测markout与成交率共同支持)。

**纪律(操作员明示)**:80.5–82¢这类具体价位是单盘事后观察,**禁止写成固定
规则**。所有退出阈值(min_profit、k、减仓触发)必须先在多路径历史数据上
验证(回放:同一入场在不同后续路径下的分布),再进影子A/B,才允许上实盘。

**优先级修正**:配对闭环(结构上不赌方向)优先于出货腿(仅在"先有利后反转"
路径有效,对"直接反向""慢走"零帮助)。本节函数同时服务两者:配对模式下它
管孤腿,front模式下它管单腿。
