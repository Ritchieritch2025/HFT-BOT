## 一、钱距度量(北极星)

Agent 优化的是被度量的东西。每个 W 开工前必须声明它拨动哪根针:
- **T-20:**距 deep03 开庭的合格日期数(数据线);
- **SLO:**封存→研究可用的小时数(时效线);
- **fees.verified / gate 数:**距"能出裁决数字"还差几道闸(解锁线)。
拨不动任何一根针的工作,不派发。"有趣但不拨针" = 记台账,不动手。
(出处:RFQ 修复螺旋——八小时没拨动任何一根针。)

## 二、对抗性分工(永不自证)

三种角色永久分离:**建造者**(写代码/跑任务)、**审计者**(只挑错,
PASS/FAKE 一票裁决)、**陪跑者**(替操作员翻译、对账、拟令)。
任何产物必须过敌对复核;测试放宽凑绿灯 = 最高级违规。
(出处:并行 agent 放宽测试被拦;三轮审计抓出 11 个真问题。)

## 三、五条刹车 + 放弃条款(防执念)

时间盒 45 分钟、修复上限 3 次、完成定义预先冻结、20 分钟心跳、
并行许可显式声明。外加**放弃条款**:每个任务开工前写明"放弃的代价"
——代价便宜的任务(如补一天数据)超时即弃,用时间替代工程。
死循环的燃料是"不能放手的执念",先掐执念。
(出处:五条刹车 deep02 验证;07-14"60 分钟不成即弃"条款。)

## 四、仓库即大脑(对抗失忆)

Agent 没有记忆,仓库就是集体记忆。铁律:
- 每个数字带出处三态(MEASURED / UNMEASURED_CONSERVATIVE / INFERRED);
- 每类事实唯一引用源(LATENCY_FACTS、fees facts、PLANS_LEDGER、
  seal status table)——不许两处为真;
- 聊天里的决定当轮落盘(E2),否则视为没发生;
- 已推翻假设入登记表,防止僵尸复活。
(出处:附录 A 七条疫苗;"6 releases≠6 天"僵尸差点复活两次。)

## 五、闸门经济学(速度与安全各归其位)

可逆且便宜 → 全自动 + 事后通知;不可逆或大钱 → 永久人闸
(实盘、删数据、凭据 IAM、>$100/月)。金丝雀分级上产线:
沙盘 → 只读演习 → 灰度 → 切换,每级一个停止门。
(出处:金丝雀在只读档拦下 10 个不符 + 1 个设计偏差,零损失。)

## 六、事故变条款(免疫系统)

每次事故/被拦/推翻,48 小时内变成一条可执行条款进相应文件,
引用实例编号。学费只交一次。
(出处:撕裂行→入册体检;OOM→强制分桶;假进度→readiness 只数真清单。)

## 七、操作员注意力是最稀缺资源(升级格式)

所有请示统一格式:**一行裁决 + 两三个选项 + 明确推荐 + 各选项代价**。
让操作员的每个决定 30 秒内可下。反例(直接打回):贴 500 行日志问
"怎么办"。操作员只出现在:批计划、批钱、批不可逆、读日报、抽查审计。
抽查审计要随机、要亲手(curl/openssl 先例)——被抽查的可能性本身
就是质量。

## 八、留白与减法(防制度癌变,操作员追加 2026-07-17)

制度只约束"结论与钱",不得侵入"尝试":

- **游乐场豁免:**隔离环境内的探索(新想法、草稿扫描、反例搜寻、
  奇思怪想)零审批、零手续、零登记义务;唯一规则 = 产物标
  `RESEARCH_DRAFT`,不冒充结论。任何人不得以流程为由拒绝一次
  便宜的尝试。
- **制度日落审查:**每到一个里程碑(deep03、shadow 首日、微实盘首日),
  对全部条款做一次减法审查:过去一段从未触发的、只产生摩擦不产生
  拦截的条款,退役进历史档;每次审查必须至少认真考虑删掉一条。
  条款和代码一样会腐烂,免疫系统本身也要被免疫。
- **元指标(测量制度自己):**每周记录两个数——"想法→判决的周期天数"
  与"每周实际验证的候选数"。任一连续两周恶化,即视为制度超重报警,
  优先怀疑流程而不是人。制度的成绩单和策略的成绩单同板展示。

## 边界诚实条款(防自欺,压轴)

本机制能保证的是:**不浪费数据、不浪费算力、不自欺、以最短路径逼近
判决时刻**。它不能保证判决结果是"有钱赚"——edge 来自市场与数据,
不来自制度。制度的全部使命,是当 edge 出现时,你的系统配得上它;
当 edge 不存在时,你的系统不会骗你说存在。
