# 风险指标框架 — 做市印钱公式的仪表盘(v1,操作员共同设计 2026-07-16)

**Status: FRAMEWORK — 指标定义即日生效;阈值数字待 deep03/影子阶段校准,
校准前标 PROVISIONAAL。本文不授权实盘。**

## 印钱公式(每一分钱的来路和漏点)

```
每笔净利 = 价差捕获 + 反转回吐 − 逆向选择 − 库存/结算损失 − 费用(maker≈0)
```

系统赚钱 ⇔ 该式滚动均值 > 0 且尾部风险受控。仪表盘按此拆解。

## A. 进攻指标(钱从哪来,决定去哪摆摊)

| 指标 | 定义 | 数据来源 | 用法 |
|---|---|---|---|
| A1 有效价差 | 报价点差 − 实测逆向选择(0.5~1.2¢,deep02) | markout 扫描 | 选市场:有效价差 ≤0 的市场不进 |
| A2 单边窗口收益密度 | 单边缺口时长 × 该市场流量(deep02 荒漠图) | onesided 扫描 | 排摊位优先级:Cycling/Golf/Baseball 缺口 |
| A3 费用墙护城河 | taker 费(50¢ 处 ≈1.6¢)− 对手改挂单的迁移率 | 费率 facts(待 ratify) | 护城河变薄(散户学会挂单)= 生意变难预警 |
| A4 时段收益画像 | 分 UTC 小时的价差×流量(deep02 节律) | intraday 扫描 | 排班:UTC 0-3 主战场 |

## B. 防守指标(钱怎么漏,每条带红线和动作)

| 指标 | 定义 | 红线(拟) | 触发动作 |
|---|---|---|---|
| B1 逆向选择率 | 我方被动成交后 1/5 分钟 markout 滚动均值 | 劣于 deep02 基线 2σ | 拉宽报价/暂停该市场 |
| B2 成交好得离谱 | 成交率显著高于回测预期(认知健康) | >预期区间上界 | 🔴 自动摘单——好消息形状的坏消息 |
| B3 成交量占比 | 我方占该市场滚动成交量比例 | >25% | 🔴 自动摘单(市场枯竭或失控) |
| B4 库存上限 | 单市场/单赛事净持仓 × 最坏结算距离 | 单赛事最大亏 ≤ 日风险预算的 X% | 超限只减不加 |
| B5 撤单可达性 | tick-to-cancel p99(LATENCY_FACTS) vs 行情突变速度 | p99 > 阈值或行情速度 > 撤单速度 | 拉宽/摘单;这是"跑得掉吗"指标 |
| B6 数据新鲜度 | 行情流最后消息年龄 | > 阈值(拟 2s) | 盲人不报价:立即摘单 |
| B7 gap 纪律 | 数据 gap 窗口 | 任何 gap | 不报价(A1 测试纲已定) |

| 指标 | 定义 | 用法 |

## D. 资金级风控(最后的保险丝,操作员专属)

| 指标 | 定义 | 动作 |
|---|---|---|
| D1 日亏 kill 线 | 当日净亏达日风险预算 | 全部摘单停机,当日不复活,次日复盘 |
| D2 回撤阶梯 | 累计回撤达 X/2X/3X | 降杠杆减半 / 只出不进 / 回影子 |
| D3 余额绊线 | 余额变动 vs 授权交易记录对账 | 对不上 = 🔴 疑似账户异常,全停 |
| D4 放量纪律 | 每次扩规模 ≤2×,且需两周复制期(G9) | 防"赚了就梭哈" |

## E. 变更风险纪律(实盘阶段生效;来源:行业事故案例,操作员 2026-07-16 采纳)

- **E1 圣域代码变更加严:**价格路径(E4 定点转换、费用计算、订单序列化)
  的任何改动 = 最高审级:等价测试(逐字节)+ 独立审计 + 认知报警武装完毕
  才准上线。"所有测试通过"不构成安全证明——测试只查想到的,市场查一切。
- **E2 止血范围 = 变更范围:**任何认知报警(B2/B3)若可归因于一次代码/
  配置变更,自动停止范围 = 该变更触达的**全部**实例,而非仅报警的实例。
  吃了同一副药的都算病人,不等发烧。
- **E3 拔电源是反射不是决策:**B2/B3 红线触发 → 机器自动摘单先行,
  人类事后复盘。禁止把自动动作降级为"通知后人工确认"。
