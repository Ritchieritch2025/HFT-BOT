# 自动做市路线图(全权托管执行计划)

目标:在 Kalshi 上跑一个**赚价差的自动做市系统**,以最小可亏损金额起步,
每一阶段有明确的进入/退出条件,任何一步不达标就不进下一步。
安全铁律:实盘开关永远需要操作员本人显式确认;kill switch 永远可用。

## 阶段 0 — 数据基础(✅ 已完成 2026-07-06)
- 24/7 三层管道:raw firehose → staging.duckdb → 每日归档
- 全市场 L1 + trades,分类系统,数据清洗(损坏行双重校验)
- 退出条件:连续 3 天归档无缺口 ← **进行中,自动累积**

## 阶段 1 — 研究工具(本周)
- `tools/mm_scan.py`:每日做市候选市场扫描(价差 × 成交量 × 深度)
- `tools/mm_backtest.py`:保守做市回测(乐观/悲观成交双边界,
  库存上限,费用模型:maker 0 费,结算按 mid 保守标记)
- 退出条件:≥7 天数据上,悲观口径下存在正期望的市场池
  (悲观口径 = 只有成交价穿过我方报价才算成交)

## 阶段 1.5 — 动态定价模型(数据积累期并行,回测负数指明的方向)
朴素跟盘的亏损 = 逆向选择成本 > 价差收入。定价模型的任务是把两边都改善:

**A. 公允价估计(fair value)——报价的锚**
- micro-price:盘口失衡加权 mid = (bid*ask_qty + ask*bid_qty)/(bid_qty+ask_qty)
- 成交流修正:近期 taker_side 失衡 → 短期漂移项(用我们的 trades 表直接标定)
- 跨市场约束:同 event 的 bracket 各腿 yes 之和 ≈ 1;偏离 → 修正各腿 fair
- 外部参照(分市场):Crypto 用 BTC/ETH 现货指数(Kalshi 结算就锚定指数,
  现货领先 Kalshi 盘口 = 最大的单一优势);Sports 留给 game_data 扩展(已在
  schema 预留,暂不建)

**B. 报价生成(Avellaneda-Stoikov 思路,离散化到美分、0-1 有界)**
- **所有偏移/半径在 log-odds 空间计算,最后映射回美分**(50c→49c 期望收益
  变化极小,2c→1c 是赔率翻倍;Kalshi 顶级做市实践者验证过的关键处理,
  mm_calibrate 已输出 vol_1min_lo / tox_120s_lo 两列 logit 空间标定量)
- reservation price = fair − inventory_skew(库存 × 风险系数 × 剩余时间)
- 半径 δ = f(该市场已实现波动, 毒性(成交后漂移), 费用=0, 最小跳动 1c)
- **时间动态(2026-07-06 审计定稿,来自"方差坍缩"分析的合规化改写):**
  (a) δ(t) 随距结算时间缩短而加宽,进入结算收敛窗口(Q6)直接停报;
  (b) 库存上限 cap(t) 随剩余时间收缩(初期允许小净仓,尾段趋零)——
      退出优先用被动偏移报价,主动打价只允许 panic 规则触发,
      "尾段一有净仓就市价对冲"是费用自杀(taker费+价差),拒绝;
  (c) 跳变熔断:**监测报价速度(log-odds mid 速度 + book 更新频率),
      不是成交爆量** —— 实测(BADAMS 板球, 2026-07-06)最大 5 分钟跳变
      37¢→28¢ 发生在零成交上,纯报价重定价;只看成交带的跳变检测器
      会完全漏掉。触发后动作 = 撤双边报价(防御),顺势吃单是另一个
      策略,须单独过悲观口径验证(P2/P3),不得混入做市器。
- 报价 = clamp(reservation ± δ) 到合法价位;库存越偏,单边越退
- requote 预算:受 token 桶约束(写配额 300/s,单市场限频)

**C. 用自己的数据标定(每天自动积累的 L1+trades 就是训练集)**
- λ(δ):挂单距 touch 距离 vs 被成交强度(泊松强度,回测器已能测)
- 毒性:成交后 30s/2min mid 漂移分布,按 category/时段分桶
- 已实现波动:按市场类型(BTC 15min ≫ 网球 ≫ 经济指标)
- 退出条件:模型化报价在悲观口径回测 ≥7 天正期望,且优于跟盘基线

## 阶段 2 — 策略实现 + 影子验证(数据达标后)
- 在 C++ 引擎策略架构里实现 maker 策略(quote/requote/库存偏移)
