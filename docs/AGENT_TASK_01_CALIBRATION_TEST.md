# Agent 任务 01：第一个真测试 —— 我的数据里有没有 YES 高估？

> 目标:在**不亏真钱**、**不搞大数据挖掘**的前提下,回答一个能一击定生死的问题。
> 这不是"让 AI 去找规律"(deep03 那条路已放弃),是"把论文已定义好的 edge,在我自己的数据上验一次"。
> 数据:现有已封存的 8 天数据(2026-07-10 至 07-17),**只读**,不需要新 AUTHORITY/ARM,不碰实盘。

---

## 这次要回答的唯一问题
**"在我全部已封存的市场里(按市场族切分),哪些族群众系统性地把 YES 买贵了(隐含 YES 价 > 真实结算率)?各自幅度多大、样本够不够?排个名,指出最肥、最可靠的战场。"**

（= 工具清单里的 T1「分类」+ T4「校准图」,顺带把 T0「读数据」的雏形做出来。数据源 = S3 全部已封存数据,不预设只看网球。）

---

## 需要操作员拍板的决定（★ = 推荐默认；想快就直接"全按推荐走"）

**D1 · 测哪些市场?(数据源 = S3 全部,这里是"怎么切分来看")**
- ★ **A. 全部已封存市场,按市场族切分、排名**(T1 分类:单名 / 宽基 / 网球 / 其他体育 / 政治 / …),每族各算校准曲线,按"高估幅度 × 样本量"排个名。**网球是候选之一,由数据排,不预设。**
- B. 只跑网球(KXATPMATCH+KXWTAMATCH)—— 想极快看一眼你原始直觉时用
- *为什么推 A:校准是同一个便宜计算,跑遍全部、切族排名,比预先钦定网球更能让数据告诉你"最肥的战场在哪";也用上了你全部数据源。这不是大数据挖掘——就一个指标(校准),不会 p-hacking。*

**D2 · 用什么价当"市场认为的概率"?**
- ★ **A. 每一笔成交的价格**(每笔成交 = 一个观察:这个价 vs 该市场最终结算)。同时按 **10¢ 分桶**、**等权 + 量权各算一遍**。
- B. 每个市场的成交量加权均价(一个市场一个点)
- *为什么推 A:论文就是这么画校准曲线的(方便直接对比),而且 8 天数据薄,每笔当一个观察=数据量最大。等权/量权的分歧本身有信息。*

**D3 · 价格范围?**
- ★ **A. 全价段 1–99¢**(校准要看整条曲线,才知道高估集中在哪——论文说中价最严重)。
- *内部价 30–70¢ 的限制是给毒性工具(T6/T7)用的,不是给校准用的。*

**D4 · 什么结果算"有 edge、值得继续"?**
- **先不锁死数字。** 让 agent 报出:曲线 + 高估幅度(百分点)+ 样本量。你对着一把明确的尺子看:
- ★ **及格线 = "中价盘的 YES 高估幅度,明显大于 我的成本(手续费 + 预期被吃)"。** 论文单名中价高估到 25pp;你体育只要有**个位数到十几 pp、且样本不太小**,就值得进下一步。

**D5 · 这次做到哪?**
- ★ **A. 只回答那一个问题**,给曲线 + 数字(最快、最防摊子铺大)。
- B. 顺便把 T0「读数据」做成可复用模块(为后面 T6/T7 铺路)
- *为什么推 A:A 做完,T0 的雏形自然也就有了;先出结论,再谈复用。*

---

## Agent 必须交付什么
1. **校准曲线**:隐含 YES 价 vs 真实结算率,10¢ 一桶,等权 + 量权两条。
2. **高估幅度**:每个价桶、以及中价段(30–70¢)的错价百分点。
3. **样本量**:结算了多少个市场、多少笔成交 —— **诚实标注**,8 天可能偏薄,统计力有限要讲清楚。
4. **一句大白话结论**:*"你的网球盘里[有/没有]系统性 YES 高估,幅度约 X pp,样本 N 个市场 / M 笔,[够/不够]支撑下一步。"*
5. 用到的数据版本、口径、代码提交号,便于复算。

## 硬约束
- 只读现有已封存的 7/10–7/17 数据;**不写生产、不碰实盘、不需要新授权**(这是对现有数据的只读研究查询)。
- 结算结果(YES/NO)从已有的 settlement 数据取;取不到的市场剔除并计数。
- 输出用**大白话**,别堆行话。
- 若样本太小到出不了可信结论,**如实说"数据不够,需要更多天"**,不许硬凑。

## 说明(给操作员)
- 这一步**不需要**回测引擎、不需要报价循环、不需要毒性工具——它只测一件事:**edge 在不在**。
- 绿灯 → 下一步造 T6/T7(毒性)+ T15(回测),把策略真正跑起来。
- 红灯(体育没有足够 YES 高估)→ 省下你后面所有白工,回头换市场或换 edge。
- 这就是"图纸 → 第一个能验证 edge 的真结果"的最小一跳。
