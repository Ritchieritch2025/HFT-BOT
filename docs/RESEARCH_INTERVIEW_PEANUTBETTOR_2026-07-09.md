## 1. 可吸收(按价值排序)

**A1. 稀疏结果市场的回测校准:池化整个分布,别只测目标市场。**
(L5415-5527)高尔夫夺冠(outright)一年就几十个结果,单测它永远没有
样本量。GP 的做法:同一个 sim 同时对 outright / top-5 / top-10 /
top-20 / 晋级线 全部出价并校验校准——同一模型的不同分位数共享参数,
"如果 spread、moneyline、total 全都校准,置信度远高于单测一个市场"
(L5493-5527)。
→ 映射到我们阶段 1.5C:公允价模型的校准不应只看被交易市场的悲观
PnL,应对**同一 event 的所有 bracket 腿、所有分位数**同时校验
(bracket 各腿本来就是同一分布的不同切片,和 outright/top-N 结构
完全同构)。低频市场(单个 BTC 日内 bracket 一天一个结果)靠池化
才能在 ≥7 天数据里达到统计上有意义的校准检验。**这是本集最值钱的
一条,建议并入 mm_backtest/mm_calibrate 的验收标准。**

**A2. 结算/规则陷阱的两个新亚类(在上集 T6"读全规则"之上)。**
- **结算日 ≠ 事件日:**Polymarket 的 MicroStrategy 卖币市场,事实
  (确实在期限内卖了)在市场结算日**之后**才由季报披露,按规则结 No;
  更乱的是结算后市场居然还开着,有人接着买 Yes(L2133-2273)。
  教训:结算依据是"结算窗口内可获得的证据",不是事后真相;
  规则文本压倒常识读法。
- **平台中途改规则/重挂市场:**Kalshi 的 Bryson 破纪录市场因为定价
  离谱、形象难看,直接下架后改规则(平局改为算破纪录)重新上架
  (L4489-4593);Epstein 名单市场按"被提及"字面结算,重仓 No 全灭
  (L4443-4460)。
→ 对我们:再加一条准入约束——**规则含模糊结算语言或平台保留单方
  修改空间的市场,降级或禁做**;crypto 指数结算(锚定明确指数值)
  是这方面最干净的品类,又一次支持先做 crypto。归入 mm_scan 规则
  (与上集 T3 同一节)。

**A3. 观察项:Kalshi 上线 perps(永续合约)。**
(L2429-2477)带杠杆、可爆仓,含 BTC/加密标的。对我们两个潜在影响:
(a) BTC perp 与我们做市的 BTC bracket 市场是同一标的的两种衍生品,
可能改变盘口 flow 结构(套利者出现);(b) 远期可能成为**平台内
对冲腿**(bracket 净仓不必跨平台对冲)。行动:排一个低优先级
调研——perps 的合约规格、费率、与 event 市场的价格联动。不动
MASTER_SEQUENCE,记 BACKLOG。

## 2. 对我们路线的再确认(无新增行动)

**C1. AI 拉平工程能力 → 竞争面变宽但变浅;耐久 edge 收敛到两处。**
"没有 AI 就没有这波 API 交易潮,程序化账户可能是原本的 20 倍"
(L1053-1065);大机构(SIG/Jump)反而被削弱,单人+AI 可竞争
(L453-508)。所有人都能搭 bot 之后,分层发生在:**fair 的质量 +
交易执行的质量**(L731-737),以及"验收 AI 产出"的能力——
"Claude 爱把问题扫到地毯下"(L1327-1343)。
