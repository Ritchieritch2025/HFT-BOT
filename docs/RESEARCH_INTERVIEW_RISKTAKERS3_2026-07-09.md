## 1. 可迁移(核心内容)

**M1. 对手流三分类 —— 只有 latency 流是纯毒,另外两类有价值。**
(K-L269-390)sharp taker 分三桶:套利者(arb)、观点型(originator)、
延迟优势型(latency/courtsider)。前两类可以共存甚至有利用价值,
latency 流"你 24/7 输给他们,零回报,也没法从中改进模型"。
→ 我们的 tox 度量目前是一维的;分类视角提出:**按成交与锚移动的
时间关系 + 成交后不同 horizon 的漂移,把流统计分层**(→ H10)。
latency 流触发熔断;opinion 流反而是公允价的修正信号
("被打之后回看,原来伤病报告 1 分钟前出了" K-L891-933 ——
成交本身就是信息)。

**M2. 单边被打时的判定规则。**
(K-L3693-3793)双边挂单被单边吃:先问"有没有明显的散户理由"
(热门队/热门标的 → 可以持有);**没有明显理由 → 被打的那边
大概率就是 -EV 的一边**,应该到对面排队被动 scratch(平仓),
绝不主动吃单出场(加 taker 费 = 离 fair 更远,K-L3391-3409)。
"两边都有成交才说明你骑在 fair 上"(K-L3739-3747)。
→ 与 MM_ROADMAP 1.5B"退出优先用被动偏移报价"完全一致,
且给出了可检验的形态(→ H11)。另:已到 fair 就该平仓,
"在 fair 持仓 = 白吃方差"(K-L3203-3227)。

**M3. 报价规模与 iceberg(冰山单:只显示小量,成交后补挂)。**
- "如果没有队列因素,最优限额低到可笑"(K-L799-851)——
  $8 限额能捕到 100% 散户流,因为散户不会一次下超过它的单。
- iceberg 在小 tick(队列不重要)时是必备武器:想吃 2 万手只显示
  500,防止被 sharp 一口打满(K-L4316-4341)。
- 但 1c tick 队列重要,每次刷新丢队列位置 —— **显示规模 vs 队列
  价值是一对可量化的权衡**(→ H12,接上集 H4/H5)。

**M4. "谁在对面"的识别启发。**
- 市价单一口扫穿多档、且不伴随锚移动 = 散户鲸(K-L4883-4909)。
- 盘上大量参与者是 bot;"bot 很难做到又狡猾又随机,戳它一下看
  反应"(K-L4658-4673)。→ 我们 shadow 阶段可以在数据里找
  确定性 bot 模式(纯观测,不下单)。

**M5. 校准文化(与 P 集 A1 呼应,更具体)。**
(K-L3809-3919)MSE/R² 没有绝对好坏,只有相对上一版模型的好坏;
判断标准用校准("说 70% 的事是不是 70% 发生");
**每次模型跑分都留档,新跑立刻对比历史**(K-L3973-3987);
测试分层:便宜的指标 sanity check → 回测 → 带分布的 sim 回测,
逐级决定是否值得花算力(K-L4005-4027)。
→ 直接写进 mm_calibrate/mm_backtest 的工作习惯,零成本采纳。

**M6. 战略确认:B > A。**
"现在做市赚钱靠的是 B(优化从散户流提款),不是 A(预测得准),
差距不接近"(K-L2855-2905);"最大化接触散户流、最小化接触
sharp,就是全部问题"(K-L687-691)。
→ 再次抬高 H7(crypto 散户流存在性)的优先级:它检验的正是 B
的前提。也解释了为什么 fee 墙重要:大户之间互不 cross 主要因为
taker 费 + tick(K-L2923-2983)。

## 2. 叙事,必须自己测

- "先挂着顶价学习就行,损失很小"(K-L3243-3379)——对手动散户
  是好建议,对自动系统 = 未定价的学费;我们的等价物是 shadow
  模式,不是真挂单。
- Kalshi leaderboard PnL 失真:多账户、跨平台对冲腿看不到,
  "Kalshi 上看着赚,其实那周期整体亏"(K-L4989-5037)。
  → 佐证上集"P&L 叙事不可引用"(EGZEE 分析 §2)。
- "A/B 测限额/价差"(K-L451-521)——理念可取(报价参数做受控
  实验),但书里没人给出实测结果,倍数与效果全是猜想。

## 3. 陷阱(新增两类)

**T-K1. palp(乌龙价)作废连坐 + 对冲腿变裸奔。**
Betfair 把整个市场**所有**成交作废,包括非乌龙价位的成交
(K-L2231-2291);Kalshi/Polymarket 尚无公开先例,处理原则未知
(K-L2329-2345)。最毒的形态:你吃到对手的乌龙价 → 去别处对冲 →
乌龙腿被作废 → **对冲腿变成裸露风险**(K-L2541-2549)。
→ 规则:异常暴利成交在结算确认前按"可能被作废"记账,
不得立即当作已实现利润去另一边加对冲。归属:阶段 3+ 运营规则。

**T-K2. 交易所裁决有利益冲突。**
交易所与部分做市商有资金关系,作废/赔付裁决无法中立
(K-L2555-2585);裁决倾向"保护生态/保护散户"(K-L2401-2441),
我们这类自动 maker 不是被保护对象。→ 与 P 集"平台中途改规则"
同一族:平台裁量权是系统性风险,只能靠限额和 T-K1 记账规则兜底。
