# 实验工厂 v1 — 所有测试走同一条流水线(给 agent + codex)

> 目的:消灭"每次测试都是手工现造"。任何想法(新函数、新参数、新槽位挑战者)
> 必须变成一张标准工单卡进厂,否则不许占用算力和注意力。
> 工厂复用现有件:grid_replay_v2(考场)+ 指标战役 v1(评分)+ 参数户口本(存档)。

## 1. 实验清单卡(唯一入口,一个实验一个 JSON)
`experiments/queue/<id>_<slot>_<name>.json`:
```json
{
  "id": "EXP-2026-0731-01",
  "slot": "sigma_estimator",            // 槽位名,见槽位注册表
  "champion": "dual_window_max",        // 现任冠军
  "challengers": ["ewma_fast", "bipower_robust"],
  "hypothesis": "跳跃后σ300拖高5分钟导致报价过宽,抗跳跃估计恢复更快",
  "data_window": {"train": "07-12..07-26", "validate": "07-27..07-30"},
  "metrics": ["T1", "T4", "T5"],        // 指标战役表编号,永远含三件套
  "paired": true,                        // 强制:同数据配对比较
  "promote_if": "VALIDATE段 净EV CI下界 > 冠军 且 T5成交率不劣于-10%",
  "kill_if": "TRAIN段全部挑战者CI上界 < 冠军点估计",
  "max_compute_hours": 2,
  "status": "queued"                     // queued|running|verdict|shadow|promoted|archived
}
```
没有 kill_if 的实验不许入队——**没有死刑条件的想法不配占用考场**。

## 2. 流水线五站(全自动流转,人只在两处出现)
```
清单卡入队 → ①回放(TRAIN选前2) → ②VALIDATE(一次,CI裁决) → ③判决书自动生成
           → ④影子A/B(仅晋升候选,≥24h) → ⑤晋升/归档(户口本记录换冠军)
```
- 人出现的两处:**写清单卡**(你或操作员)、**读判决书**(格式固定,只看数字)。
- 中间站全部自动:考场调 grid_replay_v2 分区并行,评分调指标战役,
  判决书写入 `experiments/verdicts/<id>.json` + 人读版 md。
- 任何站失败(基线门、数据缺口、SHA 不合)→ 状态=voided,原因入判决书,不静默。

## 3. 判决书固定格式(所有实验长一样,可跨实验 diff)
每份判决书只有四节:清单卡回显 / 每挑战者 VALIDATE 数字表(n、EV、CI、三件套)/
promote_if 与 kill_if 的逐条判定(过/不过,不许"接近")/ 下一步(晋升影子|归档|留任)。
均值不加粗,CI 下界加粗——**报数报区间,选人看下界**。

## 4. 排队纪律(防组合爆炸)
- **同一时刻只有一个槽位在赛**(坐标下降);其他清单卡排队。
- 每槽位每赛季挑战者 ≤4;想测第 5 个,先归档一个。
- 队列按"预期影响×证据成本"排序,操作员每周批一次队列顺序。
- 全组合网格永久禁止;疑似强交互的两槽位,合并立项为一个复合槽位实验。

## 5. 槽位注册表(工厂的产品目录)
`experiments/slots.json`:每槽位记录——接口(输入/输出签名)、现任冠军、
上任日期、上任时判决书 id、历史冠军链。这是系统进化史的家谱,
面板(param_dashboard)加一页渲染它。

## 6. 归档与复用
- 一切实验产物(清单卡、原始输出、判决书)进 `experiments/archive/<id>/`,
  永不删除——被否决的想法带着数字入土,防止半年后换个名字还魂。
- `experiments/index.csv` 一行一实验:id、槽位、结论、冠军是否易主——
  工厂的总账,趋势 = 系统进化速度。

## 7. первый批入厂的实验(按序)
1. EXP 退出策略(第2轮回放,已在跑——补一张清单卡追认,判决书按本格式补写)
2. EXP margin函数:flat2.5 vs 毒性表 vs 毒性表×VPIN
3. EXP σ估计器:dual_max vs EWMA vs bipower(校准工具已就位)
4. EXP fair尾部:Φ vs t分布 vs 经验分位(极端区分层判定)
5. EXP 三堆孤腿归因(非槽位,分析型实验——工厂同样收:有假设、有kill_if)
