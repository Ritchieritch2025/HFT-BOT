# PROMPT — 盈利条件地图(EV 状态表,原样粘贴给 agent)

目标:回答一个问题——**"我们的策略在什么状态下期望赚钱、什么状态下期望亏钱"**,
输出一张可直接当入场门用的状态 EV 表。不是新防御机制,是给现有所有机制一张总地图。

## 第一步:给每个历史"入场机会"打状态标签
用存量数据(13h 影子回执 + 回放数据 + 仓库 tape),对每笔成交(以及每个被 gate
拒绝的入场评估,作为对照组)记录**入场时刻可观测**的状态向量,全部按既定纪律
取 tte 分层 + 时段日历化的百分位,禁止裸值、禁止任何事后信息:

- 双向性:过去 60s min(YES taker 量, NO taker 量)/总量(自然配对率代理)
- 流强度:taker 量速率百分位
- 毒性浓度:VPIN 百分位(全曲线汇总口径;若 VPIN 未过增量检验则用 σ×量百分位)
- 波动状态:σ 百分位 + 距最近 4σ 跳的秒数
- 价区:该腿的 YES 等价价区(5 桶)+ 便宜侧/贵侧标记
- 模型分歧:|fair − mid| 百分位
- 生命周期:tte 段
- 动量:标的 15s 动量 z 与该腿方向的同向/逆向

## 第二步:算每格 EV
结果变量 = 该入场的完整周期盈亏(配对锁差 − 孤腿退出成本 − 费用),
不是单腿 markout。按状态维度单独 + 两两组合分格,每格给:
n、EV 均值、EV 中位数、正 EV 占比、95% 区间(bootstrap)。
样本 < 30 的格子标灰不给结论。

## 第三步:找最小分割
用最简单的方法(单层决策树/分层表,禁止黑盒模型)找出**用最少条件把
正 EV 和负 EV 分开**的规则组合。预期形态类似(以数据为准,不许硬凑):
  绿:双向性>中位 且 VPIN<70pct 且 非50–65¢中间带 → 挂满
  黄:单一条件恶化 → 挂但要价按毒性表加成
  红:VPIN>90pct 或 距4σ跳<30s 或 双向性死 → 停止新入场
输出这张红绿灯表 + 每个状态的历史 EV 证据。

## 第四步:验证与接线
- 按天切分:前段日期建表,后段日期验证红绿灯的分类是否稳定(格子 EV 符号翻转
  的比例要报告)。
- 经济账:如果历史上只在绿灯状态入场,总 PnL、成交量、每小时收入各是多少?
  对比现状。这是"策略在什么情况下挣钱"的最终数字答案。
- 接线:红绿灯 = 入场门的最外层(在毒性表加价之前),状态实时可算
  (所有输入都是 INDICATOR_STATE 已规划的指标)。影子 A/B 同报三件套:
  markout、成交率、净利润。

## 纪律
- 状态必须入场时刻可观测,任何用到未来数据的特征直接作废该行。
- 对照组(被拒入场)同样打标签——用来估计"如果当时入场会怎样"的机会成本,
  防止把门修得只会说不。
- 结论标注 [实测] / [样本不足] / [假设],格子证据全部入 receipts。
