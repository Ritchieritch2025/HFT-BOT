# 建造计划：别人验证过的策略 → 测试 → 落地模型和公式

> **输入** = 5 篇论文已验证的结论(不是让 AI 从零挖规律)。依据见 `MM_DOCTRINE_FROM_LITERATURE.md`。
> **每阶段的骨架**:①依据(哪篇验证过的)→ ②在我数据上测它成不成立 → ③成立才落地它的公式/模型 → ④**决策门:agent 用"选项+推荐默认"问我具体问题**,不许自己猜关键定义 → ⑤过/不过 gate。
> **纪律**:全程只读现有数据、不碰实盘,直到 Phase 5;拿真钱只做微调,发现全在回测里做完。
> ★ = 推荐默认(想快就"全按推荐走")。

---

## Phase 0 · 数据地基（T0–T3）
- **落地**:tape 读取器(成交带 taker 方向 + 盘口 + 结算)、费用内核(你验过的二次 maker 费)、mid/log-odds 原语、市场分类器。
- **决策门**
  - Q0.1 数据源? ★现有 8 天已封存数据(7/10–17)
  - Q0.2 时钟? ★收报时钟(你定过的);对校准这步影响小
  - Q0.3 数据源 / 怎么切分? ★数据源 = **S3 全部已封存市场**;第一测试按**市场族切分、排名**(不预设只看网球)
- **过关**:能干净读出任一网球盘的成交+价+结算,计数无缺口。

## Phase 1 · edge 在不在？（T4 校准）— 一击定生死
- **依据**:单名有系统性 YES 高估、赢家 fade 它(#2 §5.4;#5)。
- **测**:**全部已封存市场,按市场族切分**,各算校准曲线(隐含价 vs 真实结算率),按"高估幅度 × 样本量"排名,指出最肥的族。
- **落地**:T1 市场分类 + 隐含价→结算率映射 = 你的 edge 地图(逐族)。
- **决策门**:见 `AGENT_TASK_01_CALIBRATION_TEST.md`(D1–D5,已做好)。
- **过/不过**:中价 YES 高估明显 > 成本 → GO;不够 → 换市场/换 edge,省下后面全部白工。

## Phase 2 · 危险能不能测出来？（T6/T7/T8/T9/T10）
- **依据**:VPIN(内部价)预测做市亏损、单边流预测结算、冲击是永久的(无反转)、大知情流会盖过行为流(Netflix)(#2 §4/§6)。
- **测**:在你数据上——高 VPIN / 大单涌入是否真预示做市亏损?能不能复现一次"Netflix 塌方"?Glosten-Harris 的 γ2 是不是 ≈0(**裁你"5 分钟反转"的真假**)?
- **落地**:签名订单流、VPIN(量桶+内部价门)、Kyle's λ(log-odds 回归)、Glosten-Harris 分解、大单检测器。
- **决策门**
  - Q2.1 内部价带? ★30–70¢
  - Q2.2 VPIN 桶大小 / 桶数? ★先按论文 $500/桶、近 20 桶(你数据量小可能要调,agent 给建议再由你定)
  - Q2.3 "大单"阈值怎么定? ★相对该市场常态量的 X 倍(agent 出候选 X,你拍)
  - Q2.4 若 γ2≈0(反转是假的)→ 放弃反转边、专做持有到结算? ★是
- **过/不过**:VPIN/大单在你数据上**真能提前预警亏损** → GO;测不出 → 毒性防御无效,回炉重想(**绝不带着无效防御上实盘**)。

## Phase 3 · 定价模型（T5 公允价 + T12 报价公式）
- **依据**:持有到结算;利润=频率edge−幅度赤字;LS-LMSR 有界亏损+vig;α=v/(n·log n)(#1/#2/#3)。
- **落地**:公允价估计器(de-vig mid + 校准 skew + 流向)、报价公式(bid/ask = p̂ − skew ± 半价差)、LS-LMSR 有界亏损形。
- **决策门**
  - Q3.1 目标 vig(抽水%)? ★从 ~2–3% 起(α=v/(n·log n),二元 n=2)
  - Q3.2 skew 幅度来源? ★直接读 Phase 1 的校准曲线
  - Q3.3 单市场最大敞口 / size 上限? ★你给个数(先极小)
  - Q3.4 公允价起步模型? ★de-vig mid + 校准修正(最简),之后用 Brier 分迭代改进
- **过关**:报价公式能跑,且在回放里最坏亏损被 C(q₀) 封住。

## Phase 4 · 回测 + 归因 + 比值（T15 / T14 / T11）
- **依据**:频率/幅度 + 4 格 + 交叉补贴比值;sanity 靶 +1.9¢/+0.8¢(#2 §5)。
- **落地**:结算式回放(悲观成交)、跑报价循环、2×2 P&L 归因、交叉补贴比值监控。
- **决策门**
  - Q4.1 悲观成交怎么假设? ★只在你被"扫过"时成交、按最差价(agent 给具体建模,你确认)
  - Q4.2 训练/验证怎么切? ★前 5 天调参、后 3 天验(样本外),防过拟合
  - Q4.3 净利到多少才算"值得上实盘"? ★扣费+悲观成交后**稳定为正、且样本外不塌**
- **过/不过**:样本外净正 → 进 Phase 5;否则回 Phase 1–3 查哪坏了。

## Phase 5 · 极小实盘（过了 Phase 4 才谈）
- **依据**:赢家=maker、winner-take-most(#5)。
- **落地**:报价循环上真盘、极小仓;挂上监控仪表盘(净利、T11 比值、成交后 markout、毒性、敞口)。
- **决策门**:上线 size、kill line、监控频率、每日复盘节奏。
- **原则**:拿真钱只微调,不做发现。

## 怎么用这份计划
1. 你现在**只需要拍 Phase 0 + Phase 1 的板**(Q0.x + D1–D5),或直接"全按推荐走"。
2. agent 按 Phase 0→1 开工,跑出"edge 在不在"的结论。
3. **每到下一个 Phase 的决策门,agent 停下来、用这张表的格式问你具体问题**,你拍完它才往下走。
4. 任一 GO/NO-GO 不过 → 停,回报根因,别硬冲。

> 这份计划的意义:agent 有清晰的路线和公式来源(论文),你有明确的决策点(这张表),**谁都不用猜,也不会变成 deep03 那种大乱炖**。
