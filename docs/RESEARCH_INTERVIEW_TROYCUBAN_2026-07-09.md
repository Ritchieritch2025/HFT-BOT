# 访谈情报分析 #4:"Why the edge in RFQs isn't the pricing"(TroyCuban, ep156)

- 日期:2026-07-09。来源:操作员上传转录稿(4530 行,全文已读),
  原文存 `docs/vendor/interview_troycuban_rfq_transcript.txt`。(T-L123) = 行号。
- 人物:28 岁,金融本科,单人(L3541),RFQ 专职 maker,2 月起步,
  **不自建任何定价模型**(T-L3329:"I don't make any of the models of my own")。

## 一行裁决

✅ 标题即结论且与我们高度相关:**RFQ 的 edge 不在定价,在基础设施**——
名称匹配的健壮性、全量日志、静默失败检测、对手过滤;他的最大单一教训
(API 静默丢弃报价,一个月后才发现,修好后成交量×4)直接验证了我们
GUARDRAILS 的"边界校验一切外部输入";另贡献两个新检查项:
**锚可操纵性**与**成交质量随规模恶化**。

---

## 1. 可迁移

**M1. Edge 分解:定价是公共品,基础设施是私有品。**
价格 feed 人人可接(T-L2107:"如果人人能拿到价格,价格就不是秘方"),
他的护城河全在工程侧:
- **名称匹配(matching)是最难也最致命的组件**(T-L1407-1447):
  feed 里的名字 ↔ Kalshi ticker 的映射错了 = Eggsy 的 spread 翻转、
  Thompson 兄弟认错人,全是同一族 bug。→ 我们的对应物:市场 ticker ↔
  现货指数/合约规格的映射表,必须有校验测试 + 变更告警
  (GUARDRAILS"验证边界输入"的具体化)。
- **全量日志,包括被过滤掉的**(T-L1465-1623):他连"quoter 决定不报"
  的记录都存,事后才能分析报价漏斗、fill% 曲线、该在哪段价格竞争。
  → 我们 shadow 模式"决策全记录"已规划;补充:**拒绝报价的决策
  与原因也要记**,否则漏斗上半段不可见。

**M2. 静默失败是成交量杀手,只有漏斗监控能发现。**
(T-L1697-1745)Kalshi API 文档说支持 4 位小数,实际第 4 位非零就
**静默丢弃**报价;他一个月后偶然发现,修复后成交量翻 4 倍。
"人们总去拧价格旋钮,其实是覆盖率 bug 在漏单。"
→ 直接映射:阶段 2 shadow 起,建**报价漏斗指标**(收到行情 → 生成
报价 → 提交 → 交易所确认,每级计数),级间比率突变 = 静默失败告警。
这比事后对账便宜且能抓到"文档与实现不符"类问题(我们的
sandbox/discovery 已经在做这类 API 实测,方向对)。

**M3. "诚实规模"测试原则。**
(T-L1843-1869)小额试跑测不出真实逆向选择:"报 $10k 被打的概率
和报 $20 完全不同,要模拟真实规模才能看到真实市场。"
→ **对阶段 4→5 是关键警告**:微实盘(1-5 张)的成交质量会系统性
**高估**放量后的质量,因为大单才吸引 sharp。放量必须分级重验,
每级重新过悲观口径,不得直接线性外推。已并入假设文档(H4 附注)。

**M4. 风控哲学:粗糙但够用,把精力花在进攻。**
(T-L2417-2529)日最大回撤 25%(≈ 四分之一 Kelly)→ 单腿上限 =
回撤/3 → 相关腿簇同额;用模拟验证最坏情形频率(~1/300 场)。
全量 mark-to-market 实时风控 = "不赚钱的第八件事",除非你像
sportsbook 一样**不能停止报价**。→ 我们能停(kill switch),
这正是散户级 maker 相对交易所的结构优势;与 MM_ROADMAP 阶段 3
风控闸的粒度选择一致,不必过度工程。

**M5. 事后分类成交的技术。**
(T-L2365-2375)用 NBA.com 逐播数据的挂钟时间对齐成交时间,
确证 courtside。→ 我们的等价物:用现货指数时间序列对齐 Kalshi 成交
(= H3/H10 的具体做法),他证明了这个流程在实战里可行且有用。

**M6. 防守难度本身就是护城河。**
(T-L3123-3137)他成交量大头在 live,**正因为** courtside 防守难,
竞争者少。→ 启发:mm_scan 选品不只看"哪里好做",也看"哪里的
防守问题我们已经解决而别人没有"——我们的报价速度熔断如果过验,
高毒时段反而可能是低竞争窗口(远期,先过 H3)。

## 3. 陷阱(新增)

**T-T1. 锚可被操纵(spoof-the-anchor)。**
(T-L3991-4011)大学篮球:Pinnacle 限额 $5k,交易所上跟 Pinnacle 的
流动性 $20M——"几笔限额单推动 Pinnacle,然后在交易所按被推歪的价
成交几百万"。**跟锚者的命门 = 锚的操纵成本 << 可套体量。**
→ 对我们:BTC/ETH 现货指数深度极大,操纵成本远高于 bracket 可套
体量,这是 crypto 锚优于体育锚的又一结构性理由;但必须**核实
Kalshi 结算用的具体指数构成**(若是薄的采样指数,结算瞬间可被打),
已并入假设文档 H13。
**T-T2. FanDuel 等书商将以交易者身份进场**(T-L3781-3861)——
锚(书商价)与交易对手合一,利益冲突;对体育锚是实害,对 crypto
锚暂无对应物,记录备查。
