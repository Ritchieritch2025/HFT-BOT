# 要造的工具清单（Tools to Build）

> 从 Bartlett & O'Hara 2026(Source #2 全文通读)+ MM doctrine 提炼。
> 原则:每个工具**单一职责、可单独造单独验**;不是把论文方法炖一锅。
> 建立 2026-07-20。工具编号 T*,对应架构里的 C* 组件。

## 决定优先级的核心洞察

整篇的游戏 = **平时收散户 YES 乐观税;真正的风险 = 个别市场里知情流盖过行为流。**
三个案例说清了:
- **Bezos**:有知情 NO surge,但散户 YES(51.8万张@19¢)盖过 NO(37万张)→ 做市仍赚 $29,274。
- **Wahlberg**:纯 YES 乐观、无知情 → 做市赚 $118 万。
- **Netflix「Warner Bros」**:知情 NO(21万)淹掉 YES(7.1万),YES 价 90¢→<40¢ → 做市亏 **$75,754**。**这是失败模式。**

⇒ 工具分两组:**A 找钱**(生成频率edge)、**B 保命**(压幅度赤字 / 检测知情流)。**B 组是重心**——你 90% 的活是别被 Netflix。

---

## 组 0 · 数据地基
- **T0 Tape 采集器** — 拉 trades(带 **taker 方向**)+ 小时 candlestick bid/ask + settlement。Kalshi REST。红利:taker 方向已标注,**免 Lee-Ready 猜测**。注意:仅 ~7% 成交有有效报价(bid>0,ask<100,ask>bid),价差类计算只能用这部分。
- **T1 市场分类器** — 每个市场打标签 single-name / broad-based / 体育…(附录 A 规则)。**一切都按类分**,不分类什么都算不对。
- **T2 mid / 隐含概率 + log-odds 原语** — mid 由 candlestick 构;价即概率(¢/100);**任何线性统计前先转 log-odds**(边界问题)。
- **T3 费用内核** — maker/taker 精确费(二次 maker 费,你已验)。

## 组 A · 找钱（生成频率 edge）
- **T4 校准图工具** — 每族:隐含 YES 价 vs 真实结算率(10¢ 桶)。**这是"YES 乐观在哪、多大"的地图 = 你的 edge 源头。** 论文单名:隐含 46¢ 的盘实际只 21% settle YES(错价 **25pp**),但**边缘几乎没有 → edge 集中在中价争议盘(30–70¢)**。⚠ **体育不在论文里,必须你自己用它测**。
- **T5 公允价估计器** — de-vig 后的 mid + 校准修正(T4)+ 流向信号(T8)。用 **Brier 分**对结算打分。

## 组 B · 保命（压幅度赤字 / 检测知情流）——重心
- **T6 大单 / 区块进场检测器 ⭐(你点名的)** — 实时逮**异常大单 / 单边量涌入**(Netflix 40 分钟 21 万 NO;Bezos 的 NO surge)。输入:滚动窗口内单边成交量 / 单笔 size;输出:超阈值报警。这是**急性**信号——VPIN 的均值来不及反应时,它先响。
- **T7 Trailing VPIN** — **$500 量桶**,近 **20 桶**平均绝对失衡;**仅内部价 30–70¢,仅 single-name**。关键:是**悬崖不是渐变**——VPIN <0.86 全程正 P&L;**>0.94 猛翻负(−$68/桶,亏损率 59%)**。⇒ 做成**阈值报警,过 0.94 就撤**。持续性信号。
- **T8 流向分类器** — trailing 签名流 >0 = YES 向。单名 Q5:YES 向的结算 YES 35.9% vs NO 向 22.0%(t=12.44)。⇒ 喂 T5,并判"这股单边流站在结算哪边"。
- **T9 Kyle's λ 估计器** — 市场级信息冲击(log-odds,5min 区间,**每市场 ≥50 个有成交区间**才可估)。哪些市场结构性毒 → **选战场**。
- **T10 Glosten-Harris 永久/暂时分解器** — 在 λ 回归上加 ΔSOF,读 γ2。**唯一职责**:这市场有没有可 fade 的暂时反转。基准率:仅 7% 市场 γ2 显著。⇒ **裁你的"网球 5 分钟反转"到底真不真**;γ2≈0 就是纯持有到结算。
- **T11 交叉补贴比值监控** — 行为税 ÷ 逆向流。论文:NO 盘 **1.52×(赚)** / YES 盘 **0.80×(亏)**。**比值 →1 = 危险**(Netflix 就是塌到 1 以下)。逼近 1 就减仓/撤。

## 组 C · 决策 / 执行
- **T12 报价引擎** — LS-LMSR:公允价(T5)+ vig(α=v/(n·log n))+ 库存 → bid/ask;de-vig 读隐含概率;有界亏损 C(q₀)。
- **T13 风控 / 组合控制器** — ⚠ **不做单笔止损**(单笔亏损是结构性的:80¢ 卖 80% 盘,设计上就输 4/5)。风险 = **组合结算敞口 + T6/T7 报警触发撤退**。C(q₀)/R(q) 封底。
- **T14 做市 P&L 归因** — 每笔/桶/市场:结算 − 成交,拆**频率 edge vs 幅度赤字** + 4 格(taker 侧 × 结算)表。既是回测指标,也是实时监控。Sanity 靶:单名 +1.9¢ / 宽基 +0.8¢。

## 组 D · 回测
- **T15 结算式回测器** — 悲观成交回放,组合 T5/T12/T13,**样本外**评估;复现频率/幅度拆解与校准。

---

## 先造哪个（依赖 + 价值）

1. **T0–T3 地基**(躲不掉)。
2. **T6 大单检测器 + T7 VPIN(保命组核心)** — 也是你能**最快独立验证**的:在历史数据上,大单涌入 / 高 VPIN 是否真的预示做市亏损?能不能复现出一个"Netflix 塌方"?过了这关,你才有资格谈上实盘。
3. **T4 校准图** — 找钱地图;**体育自测**,让数据告诉你体育有多少 YES 乐观。
4. 再 T5 / T8 / T10 → T12 / T13 / T14 → T15。

> 一句话:**A 组告诉你哪里有钱,B 组保证你别在拿钱时被知情流打死。先把 B 组(尤其 T6/T7)在历史数据上验出来,是最靠近实盘、又最防自欺的一步。**
