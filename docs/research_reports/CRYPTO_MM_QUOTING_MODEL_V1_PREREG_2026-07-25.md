# CRYPTO-MM 挂单模型 v1 预注册(BTC/ETH 15分钟+小时线)

日期:2026-07-25 · 只读预注册;实盘开闸另需影子判决 + 操作员授权
上游:定价内核 `tools/research/crypto_mm/rti_pricing.py`(已测);影子引擎 `shadow_quoter.py`
口径:审计十条成交真实性 + 2026-07-25 分层原则(逐 series 报,禁混池)
槽位标记:`[SHADOW]` = 由影子实测值代入后本规格才生效;代入即封印,不得再调。

## 0. 边际论点(一句话)
锚新鲜度已定界为 ±60s = ±6¢/张;本模型的全部工作 = 拿秒级 RTI 正版锚,
只在 FV 显示某侧便宜 ≥θ 时站到那一侧的队尾,风暴不追、结算不碰。

## 1. 选边与挂价(定价模型 → 动作)
- FV = `p_settle_above(RTI, strike, σ, tte, locked)`;
- edge_yes = 100·FV − yes_bid;edge_no = (100−100·FV) − no_bid;
- 挂单条件:edge ≥ θ,θ = `[SHADOW: 取影子 θ∈{2,3,4} 中净益/成交率乘积最优档]`;
- 挂价 = 该侧当前最优 bid **队尾加入**(不越价、不改良);FV 移动使 edge < θ/2 → 撤;
- 窗口纪律:15M 系列 10m ≤ tte < 30m 挂、tte = 5m 硬撤;小时线 `[SHADOW: 按其房间图重标定,初值 tte≥30m 挂、tte=10m 撤]`;
- 风暴闸:滚动 10s 盘口变价 ≥ 4 次(毫秒普查口径)期间**不新挂**,已挂不追撤(实测撤不过子弹,靠站位不靠反应)。

## 2. 仓位与库存($200 全账户)
- clip = 5 张;单市场单侧最多 1 个 clip;
- 敞口上限:单市场 ≤ $10;单 series ≤ $60;**全账户在险 ≤ $150**($50 现金缓冲吃手续费与滑点);
- 同时在场窗口数 ≤ `[SHADOW: 按实测成交率反推,使日成交笔数期望 ∈ 20–60]`;
- **库存偏斜**:某市场持净多 YES 后,该市场只允许挂 NO 侧(反之亦然)——先平衡后扩张;
- 结算持有:允许(15 分钟自动清零);跨窗口净敞口不滚动累积。

## 3. 规模依据(诚实版 Kelly)
- 影子实测每张净益 μ̂ 与其 CI 下界 μ_lo `[SHADOW]`;每张结算方差 ≈ p(1−p)·10⁴;
- 用 **μ_lo(不是 μ̂)** 算 ¼-Kelly 得出单窗口在险占比;若 ¼-Kelly 建议 < 上表硬上限,取小者;
- μ_lo ≤ 0 ⇒ 本规格整体无效,不部署(这不是参数,是开关)。

## 4. 杀门(预先承诺,触发即停)
1. 实盘累计净亏 ≥ $50(账户 25%);
2. 任意一日与交易所对账出现 ≥1 分钱无法解释;
3. 连续 3 个交易日实测每张净益 < μ_lo − 2¢;
4. 实测成交率 < 影子预测的一半(成交模型失真,回炉);
5. 锚断流 > 60s:全撤并停机至恢复(无锚不挂单,永远)。

## 5. 晋级门($200 → $1,000)
≥100 笔实盘成交、逐分钱对账全通过、净益 CI 下界 > 0、
且实测边际与影子差 < 1¢ —— 四条全满足,报操作员批。

## 6. 报告纪律
逐日:成交数/净益/库存峰值/风暴闸触发次数/锚延迟 p50、p99;
逐 series 分报,禁混池;每周滚动重估 μ̂ 并检查杀门 3。

最大的洞(自报):tail-queue 假设在实盘可能偏悲观(我们排队尾,真实排位
可能更好)——这只会使实盘好于影子,方向安全;反向风险是影子期恰逢
低波动周,μ̂ 高估,由杀门 3 兜底。
