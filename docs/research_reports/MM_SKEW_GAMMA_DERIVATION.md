# MM 库存偏斜系数 γ 推导(BTC15M 做市引擎,F1)

日期:2026-07-25 · 状态:γ 默认 0.5 c/张,**待 grid_replay_v2 回放三点包围(0.2/0.5/1.0)裁决后冻结**

## 机制

净仓 `net = y − n`(张)。累积方向的报价按

```
retreat = γ · |net|   (美分)
```

后撤,并向下取到该价格带的合法 tick(中带整美分、尾带 0.1 美分——向下=离市场更远=保守方向)。对冲方向的报价永不后撤(它减少库存)。硬闩 `|net| ≥ MAX_NET` 保持不变,是最后一道墙;γ 的职责是让这道墙**几乎永远碰不到**。

这是 Avellaneda–Stoikov 保留价格 `r = s − q·γ_AS·σ²·τ` 的二元结算版:我们不移动双边中心,只把危险的一侧移开(对冲侧价格提升被 A3 tick 规则和 post_only 禁止,而且回放的成交模型无法给激进改价以可信成交——只许悲观方向)。

## 约束一:资本(下界)

- 实盘参数:bankroll $10,`MM_MAX_COST` $8,clip 2 张,`MAX_NET` 6 张。
- 最坏单市场堆积 6 张 @ ~50c = $3,占 bankroll 30%。07-25 两次事故(180 张 / 58 张)就是这个约束失效的样子。
- 要求:后撤在 `net → MAX_NET` 之前把继续成交的概率压到边缘。等价条件:`γ · MAX_NET ≥ D`,其中 D = 成交所需的穿透深度(taker 打穿 best 之下 D 美分才能吃到我们)。

## 约束二:经济(上界与量纲)

后撤 γ·|net| 的含义 = **每多持一张库存,向市场多要 γ 美分的边际补偿**。上界:后撤太深 → 永不成交 → 等价于只剩硬闩(γ→∞ 退化为现状)。γ 的合理区间由两个测量锚定:

1. **逆向选择的量级**:已知答案墓地(tte<2m 全档)实测 −3.198/−3.654 c/张(e4_front KA,全字段复现);E2 房间图杀伤区 lt2m mid −1.7c。即被单边打穿时的典型损失量级 ≈ 3c/张。
2. **要求**:满仓(MAX_NET=6)时要求的边际补偿应覆盖该量级:

```
γ = D / MAX_NET ≈ 3.0c / 6 张 = 0.5 c/张
```
