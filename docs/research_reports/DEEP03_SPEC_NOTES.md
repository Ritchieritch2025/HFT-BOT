## 2026-07-16 操作员裁定:废除"热门/冷门"二分

- **裁定原文(意译):** 不用热门/冷门来区分,50/50、49/51 甚至 45/55 区别没那么大;
  就观察数据本身。
- **落实方式:** markout 及一切按价格条件化的分析,不再用 50¢ 硬分界打标签;
  改为按成交价格**连续分段**报告(如 <10¢ / 10-30 / 30-45 / 45-55 / 55-70 /
  70-90 / >90¢,或直接画价格×markout 的连续曲线),让读者自己看形状,
  不预设"favorite-longshot"叙事。
- **背景:** deep02 扫描 1 用了"taker 所买侧价格 ≥50¢=favorite"的冻结二分,
  分界附近样本会稀释组间差异;该结果仍有效(EXPLORATORY),但表述方式不延续。
- **注意:** 分段边界仍须在跑数前冻结(预注册纪律不变),只是从"二分+叙事标签"
  改为"多段+中性描述"。

## 2026-07-16 补充 2:90 拉锯区双边报价(操作员直觉 + 当场验证)

- 实测(网球 07-12/13,窗口内收尾的盘):摸到 99 的 413 场最终翻盘仅 1.0%,
  但其价格路径平均穿越 90 线 11.5 次、跌破 80 线 7.9 次 → 90 一带是高频拉锯区。
- 精修口径(摸到过 90、窗口内收尾):翻盘率 07-12/13 = 5.1%(n=511),
  07-15 = 4.8%(n=414,已封存未发布、参考),三天合并 5.0%(n=925)——跨天高度稳定。
  穿越 90 次数:中位 7、平均 ~13、p90 = 23~35、极端 193/239 次。
  注意:此为"曾摸到 90"口径,不可直接与"90 时点定价"比较;时点口径留给 deep03。
- 叠加价格×走向曲线:89–93¢ 段吃单者平均 markout ≈ 0 → 该区间 maker 的
  逆向选择成本近零。
- 候选形态:在 88–93 区间双边挂单,收比分拉锯的重复价差(每场可成交 ~10 次量级),
  真翻盘(该区 ~10–20%)时的止损/kill 条件是生死线。
- deep03 要求:按日稳定性、逐场 PnL 分布(含翻盘场)、悲观成交口径、
  与 C1-PREMATCH-TTS-01 的窗口划分关系。数据出处:本会话即席查询
  (readonly,生产归档 07-12/13),需在 deep03 用正典发布复算。

## 2026-07-16 补充 3:niche 分解为硬性要求(操作员提出集中度疑虑)

- 疑虑:汇总统计可能被少数联赛/赛事类型拉高。初查(正典两天,摸到90网球盘):
  翻盘率 ATP 5.6% / ITFW 4.7% / WTA 6.6% / ITFM 2.4%(格内翻盘仅 2–10 场,
  差异暂无统计力);穿越90均值 ITF女子 14.8 vs ATP 8.6 —— 拉锯频率的联赛差异
  是真实的,低级别赛事更 streaky。
- deep03 硬性要求:①一切经济量按联赛(group/series)分解;②"删最佳子类"
  稳健性检验(删后优势消失=集中度假象);③niche 判据 = 拉锯频率 × 可成交量 ×
  价差宽度 − 翻盘损耗,四量齐测(低级别赛盘口薄,频率高不等于容量大);
  ④按赛制(bo3/bo5)与赛前/盘中分层留作二级分解。

## 2026-07-16 补充 4:撤退→张开→放量时序获得统计确认(操作员盘口目击 + 复核)

- 观察:焦灼时刻顶层挂单消失、spread 张大、随后突然放量(操作员实时盘口目击)。
- 复核(正典两天,网球,n=37,108 个 1s≥8 笔的放量点):放量前 30~3s 价差中位
  1.23× 正常值,35.5% 的放量点前价差 >1.5×;放量后 3~30s 回落至 1.13×。
- 机制解读:比分敏感的专业 maker 在关键分前撤单(courtsiding 信息不对称),
  分毕知情流吃残单造成放量,随后重新报价闭合。
- deep03 落点:①防守——C1-HFOLLOW-RETREAT-01 从假设升级为拉锯区策略的
  必备 kill 信号(L2 深度协同蒸发 → 撤单),量化其提前量与误报率;
  ②进攻——"分毕价差重建"窗口(秒级)的可捕获价差与竞争密度;
  ③两者都依赖 L2 天数积累(deep01 时仅 1 个有效 L2 日)。

## 2026-07-16 补充 5:"驻军指数"选品筛选(操作员盘口观察:$200k+/场已有职业 MM)

- 观察:高成交量场次的 orderbook 呈职业做市指纹(比分联动报价、关键分协同撤退、
  快速重报)。职业 MM 需大成交量摊销传分/基建成本 → 只驻扎头部场次。
- 策略定位:不与职业盘在头部市场正面竞争;目标市场 = 拉锯频率 × 真实散户流量 ×
  无职业驻军。
- deep03 新增工件:每市场"驻军指数"(occupancy score)——双边在线率、成交后
  重报延迟、价差贴近度、关键分前协同撤退是否出现;用于自动选品与排除。
- 风险镜像记录:无人区缺乏纠错方,错价暴露时间长;报价模型的独立定价能力
  要求更高,单市场敞口帽更紧。

## 2026-07-16 补充 6:外部数据源的"失明成本"量化(操作员预判可能避免不了外接)

- 立场:当前策略组合(赛前/无人区/跟随撤退)按"无外源"设计;外源接入不预设,
  由数据定价后再决策,符合 D-1(外部工具全部冻结、一事一批)。
- deep03 新作业:量化盘中策略的"失明成本"——撤退信号相对放量的提前量分布、
  误报率、被击中损失中"仅比分直连可避免"的比例 → 得出外源的可支付上限价;
  与候选比分 API 的报价/延迟档位对比,差价为正才立项报批。
- 明确不做:头部市场正面拼速度所需的场边级传分(该战线已放弃)。
