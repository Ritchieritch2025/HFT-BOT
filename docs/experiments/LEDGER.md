### E10 尾部方向探查(2026-07-27,**证据不足,不得作为决策依据**)

89个已结算KXBTC15M,影子QUOTE_EVAL的mid_c(真实盘口)vs API的settled result:
低价区(YES 0-25¢)市场价高于实际发生率(+6.6~+21.7),高价区(75-100¢)市场价
低于实际(−2.4~−7.0)——**方向与彩票效应一致(小概率被高估),即"只买便宜侧"
这条规则可能是反的**。

**但三个缺陷使其不能支持任何规则变更**:①n=5~34,方差压倒信号(真实概率20%时
连续5次不发生的概率33%,8次全不中61%——观测到的"全归零"完全在随机范围内);
②采样用"该时段中位那条回执"代表整段,有选择偏差;③桶内混合了不同真实概率的
市场,聚合偏误。

**升级为证据需要**:几百-上千市场(现89)、按概率格子而非价区分层、固定时点采样、
把"卖便宜侧收益"与"224×肥尾跳空损失"计入同一净值账本。数据可从仓库历史L2重建。

### E13 σ_c曲面研究(2026-07-27,**操作员设计裁决:秒数分桶退役**)

操作员提问"结论按秒数分桶还是按价位?"→ 答案:两者都是影子,真变量是
(价区≈p, σ_c=|dP/dS|·σ·√τ)。同一300万笔按σ_c五档重分层,结构清晰:
- **便宜侧(0-35¢)买盘毒性随σ_c单调上升**:g1 +2.2 → g5 −16.9
  (狙击手公式:利润=信息领先×dP/dS,无火药无狙击);
- **贵侧(65-100¢)买盘方向翻转,毒性随σ_c单调下降**:g1 −24 → g5 +17
  (平静时买热门=知情建仓;混乱时追热门=恐慌盘送钱);
- 中间区主体(n=39-42万)对σ_c不敏感,±0.7¢。
E11的tte格子是这个曲面的粗糙投影(墓地区=高σ_c端)。**引擎毒性表第三维
已从tte换成σ_c五档**(与传导层同一个量,跨市况自动迁移),先验换用
`tape_gamma_study.json`(70格)。

### L1 字段语义教训(必须记住,读错=误判整个仓位方向)

同一笔成交,交易所回执 `side:"no", action:"sell", no_price_dollars:0.79`,
而Kalshi界面显示 **"No / Cost $0.79 / Avg price 79¢"=买入NO**。
单看`action`会把"买NO"读成"卖NO"→方向反转→最大亏损从79¢误判为21¢。
**规矩:仓位方向只认 `outcome_side`+`book_side` 组合(引擎的fill_engine_side
已如此实现),永不单读`action`或`side`;人工核对以界面/positions的
market_exposure为准。**

## 增量阶梯纪律(2026-07-27立,运行编号即阶梯档位)

**每次运行只加一块**,否则总结果无法归因。任何跳档=作废重跑。

| 档 | 配置 | 新增被验证的函数 |
|---|---|---|
| **A** | front闩锁原样(盾关) | 真实成交率/费率/队列位置、撤单竞赛结局、deadman契约、全链RTT、定价核实盘校准 |
| **B** | A + 真快锚盾 | 盾拦截率、误杀成本(拦掉的单事后markout是毒是好)、dP/dS实盘准确度 |
| **C** | B + 归一化edge(σ_contract刻度) | 跨价区门槛可比性(验收:各价区基线markout坍缩同分布) |
| **D** | C + 锚修正毒性标签(v2)加价 | 毒性表增量价值、v1−v2差值=自身慢速成本(应趋零) |
| **E** | D + 动态size(Kelly分数) | size分级的净EV贡献 |

**每档固定七项对照指标**:净PnL / 成交率 / markout(5s·30s·结算) / 配对率 / 孤腿损失(总额+p95) / 库存峰值 / **撤单后被打率**。

**未定案清单**(等阶梯逐档回答):真盾降被打率?归一化edge优于cents?锚接入后σ该去趋势?VPIN有增量?动态size改善EV?尾部便宜侧可持续?**整机叠加后是否仍赚钱(重复加价/永不成交/撤了又挂/风险变小利润消失)**。

**已知未测/半测**:σ窗口消融(仅σ60 / 仅σ300 / max / 去均值residual / σ+锚)、margin合成方式(max vs sum vs 交互项)、log-odds门槛、连续加价版收割门、尾部区完整策略、BOOK_GUARD阈值ROC。
