## 一行裁决

✅ 他们的 edge 拆开后是 4 层:**费率结构(市场给的)> 参照物领先性
(基础设施决定的)> 散户流存在性(品类决定的)> 运营纪律(自己挣的)**;

## 0. Edge 到底来自哪里(拆解,不是结论)

把 Eggsy 说的"我赚钱"拆成互相独立的来源,逐层问"这层换到我们身上还在吗":

| 层 | 内容 | 出处 | 可迁移? |
|---|---|---|---|
| L1 费率结构 | maker 0 费 / taker ~7%,sharp 要吃你先跨费用墙 | E-L2035-2041 | ✅ 平台层面,同样保护我们 → H1 |
| L2 参照物领先 | Pinnacle 领先 Kalshi 体育盘;他比别人先看到 Pinnacle 动 | E-L1279, E-L1949 | ✅ 结构同构:现货指数领先 crypto 盘 → H2/H3,但**领先幅度必须实测** |
| L3 散户流(rec flow) | 体育有天然大量散户,RFQ 组合尤甚,坏单只占 ~0.1-1% | E-L1873-1887 | ⚠️ **最不可迁移的一层**:crypto 品类的散户流存在性未知 → H7 |
| L4 运营纪律 | 监控、心跳、异常告警、bug 伤疤 | E-L1143-1239 | ✅ 是前提不是 edge;缺了它 L1-L3 全会被 bug 亏掉 |
| L5 对手方识别 | RFQ 带 requester ID 可拉黑 | E-L1683-1706 | ❌ 仅 RFQ 有;CLOB 上不存在;且多账户可绕(E-L1823-1827) |

关键洞察:Eggsy 的钱主要来自 L1×L2×L3 的乘积。我们的系统设计
(MM_ROADMAP 1.5)已覆盖 L1/L2/L4;**L3 是唯一没有证据的乘数,
如果 crypto 品类的对手盘全是机器人,价差收入假设整体坍塌。**

## 4. 可验证假设(核心产出;全部按悲观口径设通过线)

格式:H# 假设 → 检验方法(用我们自己的数据)→ 通过标准 → 归属阶段。
**任何 H 不通过 = 对应策略假设作废,不得"调参到通过"。**

- **H1(费用墙)**:在 Kalshi crypto 市场,taker 费形成的无套利带宽
  足以让"锚±带宽"内的报价在悲观成交口径下价差收入 > 逆向选择成本。
  检验:mm_backtest 全费用模型,≥7 天仓库数据,分市场统计。
  通过线:悲观口径净期望 > 0 的市场池非空。归属:阶段 1 退出条件
  (已在 MM_ROADMAP,此处只是把"费用墙"显式列为被检对象)。

- **H2(锚领先性)**:现货指数领先 Kalshi BTC/ETH bracket 盘口的
  时间差,在 p95 分位上仍大于我们端到端反应延迟。
  检验:仓库数据做 lead-lag 互相关。**依赖:BACKLOG 里的
  timestamp-ladder(本地时钟列)先落地,否则用交易所时钟测出来的
  领先是 look-ahead 假象。**通过线:p95(不是中位数)领先 > 实测
  RTT + 处理延迟。归属:阶段 1.5A。

- **H3(毒性集中度)**:锚快速移动后 N 秒内发生的成交,其 tox
  (成交后 30s/2min mid 漂移)显著差于平静期成交 —— 即"我们的
  courtsider"存在且可被报价速度熔断拦截。
  检验:trades × L1,按"锚刚动"标志分桶对比毒性分布。
  通过线:两桶差异显著且熔断窗口能覆盖坏桶的多数质量。归属:1.5B(c)。

- **H4(规模-毒性)**:大额 taker 成交后的价格漂移显著大于小额
  (以市场公开成交为代理),支持"挂单规模 = f(毒性)"。
  检验:trades 表按成交量分位 × 后续漂移。通过线:单调关系成立。
  归属:1.5B 报价生成(size 维度)。

- **H5(队列价值)**:同价位队列深度显著影响被成交概率与成交质量,
  值得为其牺牲部分价差。检验:λ(δ) 标定加队列维度(L1 有 qty)。
  通过线:加维度后回测预测成交率误差显著下降。归属:1.5C。

- **H6(event 级相关性)**:同 event bracket 各腿的敞口相关系数高到
  按 market 计限额会低估真实风险 ≥ k 倍。检验:仓库内各腿价格
  联动统计。产出:event 级聚合上限的参数依据。归属:阶段 3 风控闸。

- **H7(散户流存在性 —— 最高优先,叙事风险最大)**:Kalshi crypto
  品类存在可统计识别的非知情流(小额、整数手、时段模式、与锚不
  同步),且其占比足以支撑做市。
  检验:trades 表成交尺寸分布/到达过程/与锚移动的同步性,与体育
  品类同口径对比。通过线:非知情流占比与到达率满足 H1 的收入端
  假设。**若不通过:crypto 做市的价差收入假设坍塌,策略重心必须
  重新评估(那是操作员决策,不在本文档)。**归属:阶段 1(mm_scan
  数据已够,可先做)。

- **H8(规则洁净度)**:候选市场规则文本无自由裁量结算语言。
  检验:非回测,人工/规则化 checklist(结算源、平台修改条款)。
  通过线:二元,含糊即降级。归属:mm_scan 准入。

- **H9(perps 交互)**:Kalshi perps 上线后 BTC bracket 的价差/毒性
  结构发生可测变化(套利者进场)。检验:上线前后同口径对比,
  数据管道已在采。通过线:无(观察项,先测量后判断)。归属:BACKLOG。

*以下三条来自第三集(RESEARCH_INTERVIEW_RISKTAKERS3_2026-07-09.md):*

- **H10(流的三分类可统计识别)**:Kalshi crypto 成交流可按
  (a) 与锚移动的时间同步性、(b) 成交后短/长 horizon 漂移,分成
  latency / opinion / rec 三层,且三层毒性显著不同(latency 最毒,
  rec 无预测力)。检验:trades × L1 × 锚时间序列聚类/分桶。
  通过线:分层后组间 tox 差异显著。产出:熔断只需拦 latency 层;
  opinion 层远期可反向用作 fair 修正信号。归属:1.5C(标定)。
  与 H3 的关系:H3 是"锚动后的成交毒不毒",H10 是完整分类学。

- **H11(单边形态 = 逆向选择信号)**:无锚移动背景下,连续单边
  被吃 N 手后,后续 mid 向持仓不利方向漂移的条件概率显著 > 50%
  ——即"没有散户理由的单边流,你就是错的一边"可量化。
  检验:仓库数据重放,统计单边成交 run 之后的漂移分布。
  通过线:条件漂移显著为负(按持仓方向)。产出:库存 skew 的
  触发阈值 + 被动 scratch 规则的参数。归属:1.5B(库存)。

- **H12(显示规模-队列权衡)**:"显示小量+成交后补挂"(iceberg
  行为)相对"一次挂足",在悲观口径下净效应为正/负取决于该市场
  队列深度与毒性——存在可标定的分界。检验:回测器加 iceberg
  策略变体,与整挂对比;需要 H5 的队列模型先行。
  通过线:至少在高毒性市场分层中 iceberg 变体悲观净期望更优。
  归属:1.5B/C。备注:1c tick 队列有价值,每次补挂丢队列位,
  这正是要量化的成本。
